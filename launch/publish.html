发布你的产品页

准备好 AI 生成的 index.html 和一个 GitHub 账号。以下步骤适用于新建公开仓库、从分支发布的单页网站。

1. 在本机检查成品

双击打开 index.html。核对产品名称、目标用户、真实功能和主按钮。用手机宽度预览，确认文字读得完。若 AI 还生成了图片或样式文件，保留它们与 HTML 的相对目录结构。

2. 把页面放到仓库根目录

  1. 在 GitHub 新建一个公开仓库，例如 my-product-page，勾选添加 README，使用默认分支 main。
  2. 打开仓库的 Code → Add file → Upload files。上传 index.html 及其引用的资源，保留相对路径，再点 Commit changes。
  3. 回到 Code 页。确认第一层就能看到小写的 index.html，图片地址形如 ./assets/photo.webp。

3. 开启 GitHub Pages

  1. 在仓库进入 Settings → Pages。在 Build and deployment 下选择 Deploy from a branch。
  2. 选择 main 和 /(root)，点 Save。
  3. 待 Actions 中的 Pages 部署成功，回到 Settings → Pages → Visit site。复制这里的完整网址，通常形如 https://用户名.github.io/仓库名/。

4. 用公开网址做最后检查

遇到问题

网址返回 404。 先看 Actions 中部署是否成功，再检查发布分支、根目录和入口文件的大小写。首页正常、图片丢失。 检查文件名大小写；项目站点部署在仓库名路径下，请使用相对资源地址。修正后提交到 main，等新一轮部署成功再刷新。
