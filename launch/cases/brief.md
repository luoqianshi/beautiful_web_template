# Paper-Master 项目简报

## 使用者和任务

为准备组会、需要定期整理文献的研究生制作一页中文项目介绍。访客应能判断手里的 PDF 或既有笔记可以生成什么，并前往官方仓库查看使用说明。

## 两版共用内容

- 产品名为 Paper-Master，定位为 AI 论文工作站。
- 首屏标题用项目名，核心文案用“一次阅读，两份产出。”
- 说明支持 Skills 的 AI 工具可以从 PDF 生成中文阅读笔记、HTML 组会幻灯片；也可从已有笔记生成幻灯片。
- 展示三个实际技能及输入输出：`lzk-paper-reading`、`html-paper-slides`、`blog-to-slides`。
- 主按钮统一写“查看 GitHub 项目”，指向作者的项目仓库。页尾提供真实的示例书柜，页头的“用这个风格做产品页”带上当前风格进入简报表单。
- 两版使用相同功能、信息顺序及主要文案。页面允许离线阅读，导航到外部项目时需要网络。插图只用于解释产品或表达书柜意象。

## 设计交付

瑞士版遵循非对称网格、无衬线字体和黑白红配色，用论文工作流图说明输入输出。学院版遵循深木色、黄铜、绯红与衬线排版，用书柜中的笔记本表达可持续归档。交付独立 HTML，测试 390 × 844 和 1440 × 900 两种视口，输出首屏缩略图。
