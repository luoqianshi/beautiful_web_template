## 布局创意 (Layout Ideas)

### Header

固定顶栏,高约 52px,背景与页面同色(暖纸白),无阴影、无毛玻璃,滚动时直接覆盖内容。三栏网格 `auto_1fr_auto`:左侧全大写 logo(CURSOR + 几何棱镜图标),居中的文字导航(Models / Product / Enterprise / Pricing / Resources,约 14px 常规字重),右侧动作组——纯文字 "Sign in" + 描边胶囊 "Contact sales" + 黑色实心胶囊 "Download"。

### Hero

左对齐编辑式开场:大标题仅两行、常规字重(400)、负字距,像杂志导语而非广告横幅;下方并排两枚胶囊按钮(主:黑底白字带 ↓ 图标;次:浅灰底深字带 → 图标)。标题区之下是一整块"媒体舞台"——大幅浪漫主义风景油画作背景,上面悬浮叠放 2-3 个产品窗口模型(桌面端、CLI),窗口为纯白卡片、4px 圆角、macOS 红绿灯圆点标题栏,窗口之间轻微错位叠压,制造"作品挂在画廊里"的策展感。

### Logo Garden

客户 logo 横排一行,灰度单色处理,上下留白收紧(约 34px),仅作信任背书,不做视觉竞争。

### Features(交替媒体面板区)

每个功能区块为"左图右文"或"右图左文"的两列布局:一侧是嵌在略深米色底板(#F2F1ED)中的媒体舞台(油画背景 + 白色 UI 模型窗),另一侧是文案列——大标题两行(第一行墨色、第二行灰色,同字号同字重,仅靠颜色分层),下方一枚朱砂橙色文字链接带 → 箭头。文案列垂直居中,最大宽度约 658px(max-w-prose)。区块高度约 700px,信息密度极低,一屏一事。

### Final CTA

全页收尾是一句居中的超大号标题 "Try Cursor now."(约 64-72px、字重 400、负字距),下方单枚黑色胶囊按钮。无副标题、无表单、无背景装饰——用留白本身制造分量。

### Footer

底色切换为更深一档的暖米色(#F2F1ED),与正文区形成"纸张叠纸张"的分层。五列链接网格(Product / Resources / Company / Legal / Connect),列标题 12-13px 灰色,链接 14px 墨色、行距慷慨。底部横条:左侧版权 + 认证徽章文字,右侧主题切换胶囊组(显示器/太阳/月亮三枚小圆钮)与语言选择器。

## 完整提示词 (Full Prompt)

# 设计风格:Cursor-Light-Warmth

## 设计哲学

### 核心原则

把开发者工具当作"被认真策展的作品"来呈现。页面几乎不使用色彩——一切情绪交给暖纸白与墨黑的温度差、古典油画的艺术史联想、以及近乎奢侈的留白。结构上信奉"一屏一事":每个区块只承担一个论点,靠垂直节奏而非视觉轰炸推进叙事。所有交互元素收敛为两种形态:黑色胶囊(行动)与文字链接(导航),拒绝按钮泛滥。

### 视觉气质

**情感关键词**:
- *温润纸感* — 背景不是纯白而是带黄调的暖纸色,像高级艺术画册的内页,长时间阅读不刺眼
- *克制自信* — 标题不用粗体、不用渐变色、不用感叹号;字重 400 + 负字距本身就是底气
- *画廊策展* — 产品 UI 被"挂"在油画上展示,暗示工具是被珍视的创作媒介,而非冷峻的工业软件
- *工程师的浪漫* — 等宽字体、diff 数字(+52 −0 绿/红)、终端窗口等代码语汇,与古典绘画并置产生张力

**此设计不是什么**:
- 不是 SaaS 蓝紫渐变风:全站没有一处蓝紫色、没有玻璃拟态
- 不是暗黑极客风:浅色暖底是默认人格,深色只作为按钮与局部文字存在
- 不是热闹营销风:无弹跳动画、无倒计时、无弹窗、emoji 几乎绝迹
- 不是高饱和撞色:唯一彩色是极少量朱砂橙,仅用于文字链接

### 此风格的 DNA

#### 1. 暖纸白三层底色
`#F7F7F4` 主背景 → `#F2F1ED` 卡片/页脚底板 → `#E6E5E0` 更深的凹陷面。三层同色相不同明度,像一叠不同克重的纸,分区不靠边框靠色阶。

#### 2. 墨色而非纯黑
所有"黑色"统一为暖调墨色 `#26251E`(带黄绿底调),按钮、正文、边框共用,与暖纸底同温,避免纯黑 #000 的冷硬。

#### 3. 胶囊按钮体系
主按钮 = 墨底白字全圆角胶囊,高约 36px,内边距约 `5.6px 15px`,文字 14px;次按钮 = 浅灰底或 1px 细描边透明底。图标(↓ →)内嵌于文字流中。

#### 4. 油画媒体舞台
功能展示一律采用"古典浪漫主义风景油画作底 + 白色产品窗口悬浮叠放"的构图。窗口 4px 圆角、红绿灯三点标题栏、极柔阴影,窗口彼此错位 8-24px。

#### 5. 双色标题法
区块标题两行同字号同字重,第一行 `#26251E`、第二行灰 `rgba(38,37,30,.55)`,用色彩完成主次而非字号字重。

#### 6. 朱砂橙单点
`#C8451D` 只出现在文字链接上(如 "Download Grok Bot →"),全站其余地方禁用彩色,让这一点橙成为记忆锚。

## 设计 Token 系统(DNA)

### 色彩策略

**色彩聚焦**:暖纸白 × 暖墨黑的双色主调,占 98% 视觉面积;朱砂橙作为唯一强调色仅用于链接;语义色(diff 增删、状态)使用低饱和绿/红。

| Token | 值 | 用法与上下文 |
|:------|:------|:----------------|
| `background` | `#F7F7F4` | 页面主背景、固定 Header |
| `surface` | `#F2F1ED` | 媒体舞台底板、Footer、凹陷区块 |
| `surface-deep` | `#E6E5E0` | 更深的内嵌面板、悬停底色 |
| `foreground` | `#26251E` | 正文、标题、主按钮底色、边框基色 |
| `foreground-invert` | `#F7F7F4` | 墨底按钮/深色块上的文字 |
| `text-muted` | `rgba(38,37,30,0.55)` | 标题第二行、副文案、页脚列标题 |
| `accent` | `#C8451D` | 文字链接、强调箭头(仅此用途) |
| `border` | `rgba(38,37,30,0.2)` | 描边按钮、分隔线(1px solid) |
| `border-hairline` | `rgba(38,37,30,0.025)` | 卡片极淡分界,近隐形 |
| `card-white` | `#FFFFFF` | 产品窗口模型、输入框 |
| `success` | `#3F7A46` | diff 新增数字 +52、状态点 |
| `error` | `#B0413E` | diff 删除数字 −0、警示 |
| `timeline-thinking` | `#DFA88F` | 时间线/活动条:思考(暖沙) |
| `timeline-grep` | `#9FC9A2` | 时间线:检索(灰绿) |
| `timeline-read` | `#9FBBE0` | 时间线:读取(灰蓝) |
| `timeline-edit` | `#C0A8DD` | 时间线:编辑(灰紫) |

**签名渐变**(如有):无彩色渐变。唯一"渐变"是媒体舞台的油彩本身,以及 Header 覆盖层:
```css
background:
  linear-gradient(rgba(38,37,30,0.05) 0%, rgba(38,37,30,0.05) 100%),
  linear-gradient(#F2F1ED 0%, #F2F1ED 100%);
```

### 字体系统

**字体配对**:
- **展示/UI 字体**:`CursorGothic`(人文主义无衬线,字怀开阔、字重仅用 400/500/600/700)— 标题、正文、按钮全用它;免费替代:`Inter Tight` 或 `Instrument Sans`,中文配 `Noto Sans SC`
- **衬线点缀**:`EB Garamond Italic` — 仅出现在媒体舞台内的"作品"文案中(如 Acme Labs 段落),制造画框内外的时代差
- **等宽字体**:`cursorMono` / `Berkeley Mono` — 代码行、diff、CLI 窗口、徽章编号;免费替代:`JetBrains Mono`

**字号阶梯与用法**:

| 元素 | 尺寸 | 字体 | 字重 | 字距 | 备注 |
|:--------|:-----|:-----|:-------|:---------|:------|
| Final CTA 标题 | 64-72px | CursorGothic | 400 | -2px | 居中,全页最大字号 |
| Hero 标题 | 36-40px | CursorGothic | 400 | -0.72px | 左对齐,两行,行高 1.2 |
| 区块标题 | 26-32px | CursorGothic | 400 | -0.325px | 双色两行法 |
| 卡片/窗口标题 | 16-20px | CursorGothic | 500-700 | normal | 产品模型内部 |
| 正文 | 16px | CursorGothic | 400 | normal | 行高 1.5,最大宽度 658px |
| 次要正文 | 14px | CursorGothic | 400 | normal | 行高 1.5,灰 |
| 按钮文字 | 14px | CursorGothic | 500 | normal | 胶囊内 |
| 代码/diff | 12-13px | cursorMono | 400-500 | normal | +绿 −红 |
| 页脚列标题 | 12-13px | CursorGothic | 400 | normal | 灰 |
| 徽章/微标签 | 11px | cursorMono | 400 | 0.04em | 大写可选 |

### 间距与布局

- **区块间距**:首屏 `112px 20px 67.2px`,标准区块 `67.2px 20px`,交替媒体区上下 0(由底板自带呼吸)
- **容器宽度**:`max-width: 1300px` 居中;文案列 `max-width: 65ch`(约 580-660px)
- **网格间隙**:媒体舞台与文案列间约 50-80px;卡片网格 10px
- **非对称模式**:Hero 左文右舞台、功能区左右交替;Final CTA 与 Footer 回归居中/对称,形成节奏收放

**常见间距阶梯**:4 / 8 / 10 / 12 / 20 / 32 / 52 / 67.2 / 112 px(以 4px 为基,大段用 1.5× 递进)

### 边框、表面与阴影

**圆角策略**:全或无——交互件一律全圆角胶囊(`border-radius: 9999px`),展示面(媒体舞台底板、窗口模型、图片)一律 4px 小圆角。不存在 8/12/16px 的中间态。

**边框**:1px solid,颜色为 `rgba(38,37,30,0.2)`;卡片分界用近隐形的 0.025 透明度;输入框聚焦时边框加深为墨色。

**阴影系统**:

| Token | 值 | 用法 |
|:------|:------|:------|
| `shadow-float` | `rgba(0,0,0,0.02) 0 0 16px, rgba(0,0,0,0.008) 0 0 8px` | 悬浮窗口模型、弹出卡片——无偏移、纯弥散,像纸面微微鼓起 |
| `shadow-none` | `none` | 按钮、Header、Footer 一律无阴影 |

**纹理与图案**:无噪点、无网格。唯一纹理来源是媒体舞台中的古典油画(笔触、画框、卡纸)。

## 组件样式与交互

### 按钮

**主按钮(胶囊)**:
- 背景:`#26251E` 墨色实心
- 文字:`#F7F7F4`,14px/500,可带 ↓ → 图标
- 圆角:9999px;高度约 36-40px,内边距 `6px 16px`
- 悬停:背景提亮一档(至 `#3A382F`)或整体 0.98 缩放,过渡 140ms
- 激活:轻微下沉 `translateY(1px)`

**次按钮**:
- 浅灰底版:背景 `#E6E5E0`、墨色文字,同胶囊形
- 描边版:透明底 + 1px `rgba(38,37,30,0.2)` 描边,悬停底色 `rgba(38,37,30,0.04)`

**文字链接**:
- 14-16px,颜色 `#C8451D`,尾部 → 箭头
- 悬停:下划线出现或箭头右移 2px(`transform 0.14s cubic-bezier(0.25,1,0.5,1)`)

### 卡片 / 产品窗口模型
- 纯白 `#FFFFFF` 底,4px 圆角,`shadow-float`
- 标题栏:34-44px 高,左侧三枚 10px 红绿灯圆点(灰阶或红黄绿),居中标题 12px 灰
- 内部分栏用 1px `rgba(38,37,30,0.08)` 竖线;列表行悬停底色 `#F7F7F4`
- diff 徽章:`+52` 绿 / `−0` 红,等宽 12px
- 叠放:同舞台内 2-3 扇窗口错位 8-24px,层级 z-index 递增,最前窗口完整、其余露出边缘

### 输入框
- 白底、1px 浅描边、胶囊或 8px 圆角,占位符灰
- 聚焦:描边变墨色,无外发光环(用边框本身表达)

### 导航
- 固定顶栏 52px,背景 `#F7F7F4` 不透明
- 链接 14px/400 墨色,悬停仅变灰或加下划线,无底色块
- 移动端:全屏抽屉,同暖纸底色,链接放大至 18px 纵排

### 徽章/标签
- 等宽小字(11px),如 `READY FOR REVIEW`、`Thought 6s`
- 胶囊或 4px 圆角,底 `rgba(38,37,30,0.05)`,字灰
- 状态点:6px 圆点,绿=完成、橙=进行中

## "大胆要素"(签名元素)

1. **油画策展舞台**:功能截图从不裸放,而是"挂"在浪漫主义风景油画上(可加细画框与黄铜展牌),把产品发布变成画廊开幕。实现:`background-image` 油画 + 绝对定位白色窗口叠放。
2. **字重 400 的巨型标题**:标题越大越不加重,Final CTA 72px 仍用常规字重 + -2px 字距,以"轻声说大事"对抗营销噪音。
3. **双色同阶标题**:区块标题两行同字号,仅第二行降为 55% 透明度墨色——用色彩层级替代字号层级。
4. **单点朱砂**:全页唯一彩色是 `#C8451D` 文字链接,数量控制在每屏 ≤1 处,稀缺性即品牌记忆。
5. **三层纸底色分区**:不用边框线切分区块,靠 `#F7F7F4 → #F2F1ED → #E6E5E0` 的明度阶梯叠出层次,页脚即"最下面那张纸"。
6. **无偏移弥散阴影**:窗口悬浮感来自 `0 0 16px rgba(0,0,0,.02)` 这种零偏移纯弥散阴影,克制到几乎不可见,只负责"离开纸面 1 毫米"。
7. **代码即装饰**:diff 数字、`~/cursor/cursor-web` 路径、Thought 6s 计时等终端语汇直接作为版面元素,不翻译、不美化,保留工程师的母语质感。

## 效果与动画

**运动哲学**:微不可察。动画只服务于"出现"这一件事,幅度以 2-8px 位移、0.7-1 缩放为限,时长 140-500ms,绝不弹跳、绝不循环抢戏。

**过渡默认**:
- 标准:`transform/opacity 0.14s cubic-bezier(0.25, 1, 0.5, 1)`
- 入场:`fadeSlideUp` — `opacity 0→1; translateY(2px→0)`
- 悬停:箭头 `translateX(2px)`、卡片 `scale(0.99)` 微沉

**关键帧动画**:
```css
@keyframes fadeSlideUp {
  from { opacity: 0; transform: translateY(2px); }
  to   { opacity: 1; transform: translateY(0); }
}
@keyframes tilePopIn {
  from { opacity: 0; transform: scale(0.7) translateY(3px); }
  to   { opacity: 1; transform: scale(1) translateY(0); }
}
@keyframes pulseSoft {
  0%, 100% { opacity: 1; }
  50%      { opacity: 0.3; }
}
```

**持续动画**:仅状态指示类(进行中任务的脉冲点 `scale 1→1.1`、打字省略号),页面主体无自动轮播。

## 响应式策略

**断点哲学**:两档为主(约 768px / 1024px)。桌面"左图右文",移动一律"上文下图"单列堆叠,媒体舞台保持全宽出血。

- **Header**:≥1024px 三栏完整;以下隐藏居中英文导航,汉堡按钮 + 全屏暖色抽屉
- **Hero**:标题占满宽度,字号 36→28px;按钮保持并排,过窄时主按钮全宽
- **媒体舞台**:窗口模型从"叠放 2-3 扇"减为 1 扇;油画背景改为中心裁切,保证窗口可读
- **Features 区块**:两列 → 单列,文案列在上、舞台在下,舞台上下留白减半
- **Footer**:五列 → 两列手风琴,列标题可点击展开

**关键适配**:
- 标题 `clamp(28px, 5vw, 72px)` 流式缩放
- 区块垂直内边距 67px → 40px
- 朱砂橙链接在移动端加大点击区(上下 padding 8px)

## 可访问性与最佳实践

**色彩对比**:墨色 `#26251E` 对暖纸白 `#F7F7F4` 对比度约 14:1(AAA);灰字 55% 透明度约 5.8:1(AA);朱砂橙对暖纸白约 5.5:1,仅限 ≥14px 链接使用。

**聚焦状态**:键盘焦点用 2px 墨色 outline + 2px offset 显示,不依赖阴影;胶囊按钮聚焦环同为胶囊形。

**触控目标**:所有胶囊按钮 ≥36px 高、水平内边距 ≥16px;导航链接点击区扩展至 44px。

**运动**:`prefers-reduced-motion: reduce` 时,入场动画降级为纯 opacity 淡入,脉冲类动画完全停止;油画视差禁用。

## 实现说明

- **组件结构**:单文件 HTML 或任意框架均可;核心组件为 `<SiteHeader>`、`<HeroStage>`(油画+窗口叠放)、`<FeatureSplit>`(媒体/文案两列)、`<PillButton>`、`<WindowMock>`(4px 圆角白卡+红绿灯标题栏)、`<FooterGrid>`
- **CSS 自定义属性**:以 `--bg / --surface / --surface-deep / --ink / --ink-muted / --accent / --border` 建主题层;深色模式只需把三层纸底换成 `#1A1915` 系、墨色反转为纸色,胶囊体系不变
- **字体加载**:CursorGothic 为专有字体,替代方案 `Instrument Sans`(或 `Inter Tight`)+ `EB Garamond:ital` + `JetBrains Mono`,Google Fonts 直链;中文配 `Noto Sans SC` / `Noto Serif SC`
- **油画素材**:使用公有领域浪漫主义风景画(透纳、弗里德里希、科尔),或经 text-to-image 生成"19世纪油画风格、柔和赭绿与金色调、无文字"的替代图
- **动画库**:无需引入;全部用 CSS keyframes + 140ms 过渡实现,IntersectionObserver 触发 `fadeSlideUp` 入场即可
