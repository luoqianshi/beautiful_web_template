# 设计风格：Moonshot-Pixel-Odyssey

## 设计哲学

### 核心原则

把"登月"当作招聘叙事本身：页面是一场从月之暗面出发的像素漫游。设计语言的根基是 1-bit 显示器美学——所有影像都被抖动（dither）成黑白点阵，所有文字都由像素字形渲染，仿佛整站运行在一台太空探测器的单色终端上。信奉"明度即色彩"：不用任何彩色（品牌蓝 token 存在但不登场），层级完全靠白—灰—黑的明度差与像素密度表达。信奉"一屏一事"：每个场景只讲一句话，滚动不是翻页而是推进航程。拒绝圆角、拒绝阴影、拒绝渐变色——留下的只有点阵、直线、字节。

### 视觉气质

**情感关键词**：
- *深空孤寂* — 大面积纯黑负空间里悬浮一枚抖动月球，孤独而庄严
- *复古终端* — 像素等宽字、尖括号、`<<<` 箭头、斜切缺口按钮，1980s 单色机的浪漫
- *克制的史诗* — 文案是诗（"来成为一束光，折射进真理未校准的裂缝"），画面却是最低分辨率的点阵，反差制造崇高
- *工程师的碑刻* — 中文竖排、弧形环绕文字、像素字形的每一格都可见，字即图形

**此设计不是什么**：
- 不是霓虹赛博朋克：没有辉光溢出、没有故障紫青色，一切辉光都收敛在灰阶内
- 不是 Material/拟物：没有圆角卡片、没有投影、没有玻璃拟态
- 不是暗色 SaaS：没有柔和的 slate 灰底 + 靛蓝按钮体系，底色就是纯 #000

### 此风格的 DNA

#### 1. 1-bit 抖动点阵影像
所有照片（月食、月球、星系、山峦）经有序抖动（Bayer/网点）转为黑白点阵，像素格肉眼可见。影像亮度越低，点越稀疏，自然融进黑底。

#### 2. 像素等宽字全站统一
Fusion Pixel 12px Mono zh_hans 一款字打天下，中英文同字形气质；字号跳跃极大（12px ↔ 64px），靠尺寸而非字族制造层级。

#### 3. 纯黑虚空 + 明度分层
背景恒为 #000，文字白/灰两档，图像是灰阶点阵。整站没有任何彩色像素。

#### 4. 终端斜切按钮
直角 1px 白描边按钮，四角有缺口（notch）切出"终端窗口"轮廓，`<<<` `>>>` 箭头包裹文字；hover 反白（白底黑字）。

#### 5. 滚动场景叙事
每屏一个 h-svh 场景，滚动推进而非平移；双箭头 ︽ + 短句提示（"滑动开启探索 / 继续了解"）是唯一的导航暗示。

#### 6. 天体图形锚点
月球以不同相位出现在每个场景（满月月食 → 孤月 → 半露月 → 椭圆章印 → 地月双球），是贯穿全站的叙事主角。

## 设计 Token 系统（DNA）

### 色彩策略

**色彩聚焦**：单色（monochrome）体系——纯黑、纯白、一档中性灰（#7A7A7A）与它们的透明度变体。原站设计系统里有 km-blue `#1783ff` 等品牌色 token，但招聘叙事页面全程不使用彩色；模板中保留 1 个点缀色 token 供链接/焦点态备用，默认仍是黑白灰。

| Token | 值 | 用法与上下文 |
|:------|:------|:----------------|
| `--bg-void` | `#000000` | 页面与所有场景的底色 |
| `--text-primary` | `#FFFFFF` | 标题、导航、主文案 |
| `--text-secondary` | `#7A7A7A` | 说明文字、滚动提示、页脚链接 |
| `--text-dim` | `#FFFFFF4D` | 极弱装饰文字、分隔提示 |
| `--border-hairline` | `#FFFFFF26` | 1px 描边、分隔线（15% 白） |
| `--fill-inverse` | `#FFFFFF` | 白色实心按钮底（反白按钮） |
| `--text-inverse` | `#000000` | 反白按钮上的文字 |
| `--accent-optional` | `#1783FF` | 备用点缀（链接焦点态），默认不用 |
| `--dot-hi` | `#FFFFFF` | 点阵影像高光点 |
| `--dot-lo` | `#000000` | 点阵影像暗部点 |

**签名"渐变"**：无彩色渐变。深度感全部来自点阵密度阶梯（如 4×4 Bayer 矩阵 16 级灰阶抖动）。

### 字体系统

**字体配对**：
- **展示字体**：`"Fusion Pixel 12px Mono zh_hans", monospace` — 巨型像素标题（40-64px），字形即图形，复古终端气质
- **UI/正文字体**：同一款 — 全站统一像素等宽，中英文无缝混排
- **字重**：仅 400 / 500 两档（像素字体没有真正的粗体，层级靠字号与明度）

**字号阶梯与用法**：

| 元素 | 尺寸 | 字体 | 字重 | 字距 | 备注 |
|:--------|:-----|:-----|:-------|:---------|:------|
| Hero 巨型标题 | 64px | Fusion Pixel | 400 | normal | 行高 64px，英文 |
| Hero 中文副题 | 30px | Fusion Pixel | 400 | normal | 行高 36px |
| 场景大标语 | 40px | Fusion Pixel | 400 | normal | 行高 40px，右对齐 |
| 区块标题 | 30px | Fusion Pixel | 500 | normal | 尖括号夹持 `‹ ›` |
| 数字统计 | 64px | Fusion Pixel | 400 | normal | 巨型数字 |
| 导航 | 16px | Fusion Pixel | 500 | normal | 行高 24px |
| 卡片标题 | 16-20px | Fusion Pixel | 500 | normal | |
| 正文/描述 | 12-14px | Fusion Pixel | 400 | normal | 灰色，行高 16-20px |
| 按钮文字 | 16px | Fusion Pixel | 500 | normal | |
| 页脚 | 12px | Fusion Pixel | 400 | normal | |

### 间距与布局

- **区块间距**：场景即区块（h-svh = 100svh），场景内元素四角/居中锚定，不依赖垂直间距堆叠
- **容器宽度**：场景元素贴边锚定（--hero-edge-x ≈ 40px 边距），内容盒最大宽度约 400-520px（文本盒刻意窄）
- **网格间隙**：Stats 五列网格 gap ≈ 18-20px；按钮组 gap 16px；导航项 gap 80px（桌面）
- **非对称模式**：Hero 四角散点（左上标题 / 左下注释盒 / 右下标语 / 底部中央提示），中央留空给影像

**常见间距值**：4 / 8 / 12 / 16 / 20 / 40 / 80（4px 像素网格对齐，所有值为 4 的倍数）

### 边框、表面与阴影

**圆角策略**：零圆角。所有元素直角（radii 全站为空）——像素美学的硬约束。

**边框**：1px solid，两种规格——`#FFFFFF`（按钮/强调）与 `#FFFFFF26`（分隔线/弱框）。

**阴影系统**：无阴影（shadows 为空）。深度只由点阵密度与明度差表达。

**纹理与图案**：
- Bayer 4×4 有序抖动点阵（影像与大底纹）
- 网点密度渐变（场景地表、云海）
- 胶片齿孔条（AGI 场景装饰）
- 虚线像素路径（流程地图连接线，dash 4-6px）

## 组件样式与交互

### 按钮

**主按钮（反白实心，如"去登月 >"）**：
- 背景：`#FFFFFF`，文字：`#000000`，圆角：0，padding：16px 40px
- 悬停：微微降白（→ `#F7F7F7`）或反色闪切，0.2s 过渡
- 形态：文字后缀 `>` 箭头，像命令行确认键

**终端按钮（如「<<< 校园招聘」）**：
- 背景：`#000000`，边框：1px `#FFFFFF`，圆角：0，padding：8px 12px（紧凑）或 12px 24px
- 签名结构：左右 `<<<` `>>>` 字符箭头 + 四角斜切缺口（用 CSS `clip-path` 或伪元素切角）
- 悬停：反白（白底黑字）0.2s cubic-bezier(0.4, 0, 0.2, 1)

**描边/幽灵按钮**：同终端按钮但去掉箭头，1px `#FFFFFF26` 描边，hover 描边亮起。

**禁用态**：文字 `#FFFFFF4D`，边框 `#FFFFFF1A`，无 hover。

### 卡片（Stats 列）
- 无底板无边框，仅顶部 1px `#FFFFFF26` 分隔线
- 结构：分隔线 → 巨型数字（64px 白）→ 小标题（16px 白）→ 描述（12px 灰）
- 悬停：顶部线条亮起（stroke-dashoffset 描线动画）或整列轻微上移 2px

### 输入框
- 直角，1px `#FFFFFF26` 描边，黑底白字，像素字体
- 聚焦：描边转 `#FFFFFF` + 外侧 1px `#FFFFFF26` 双线（终端光标感），无圆角无阴影

### 导航
- 透明顶栏 60px，logo 左 + 文字导航右，16px/500
- 链接 hover：文字保持白，下方 1px 白线描出（0.2s）
- 移动端：汉堡钮变全屏黑幕，链接竖排大字（每字一行，终端菜单感）

### 徽章/标签
- 直角小盒，1px `#FFFFFF26` 描边，12px 灰字，padding 2px 4px
- 数字角标（流程图 ①②③④）：白底黑字小方块，贴在圆形图标右上

### 滚动提示
- 双箭头 `︽`（两层 chevron 叠放）+ 12px 灰字（"滑动开启探索"）
- 持续微动画：上下轻浮动 2-4px

### 页脚
- 上层：延续场景背景图（低明度点阵），下层：纯黑
- 左：logo + 12px 灰版权两行；右：两列链接（列标题 12px 白，链接 12px 灰，行距 30px）

## "大胆要素"（签名元素）

1. **1-bit 抖动影像**：任何配图必须先转黑白点阵（Bayer 有序抖动或半调网点）再使用——直接放灰度照片会立刻破坏 DNA。实现：canvas 实时抖动、预处理 PNG，或 1-bit 像素艺术风格生图。
2. **像素字形即装饰**：Fusion Pixel 的锯齿轮廓是核心质感，禁止用抗锯齿无衬线"平替"；字号放大时字形方块感越强，40-64px 大字本身就是图形元素。
3. **零圆角零阴影**：直角 + 1px 白描边的硬约束，任何圆角/投影都会引入"现代 SaaS 味"。
4. **终端斜切缺口按钮**：`<<< 文字 >>>` 字符箭头 + 切角轮廓，是全站唯一的"图形化按钮"语言。
5. **纯黑负空间构图**：场景中央大面积留黑给点阵天体，文字压四角——克制到近乎傲慢。
6. **月相叙事**：天体图形随滚动换相位（月食→孤月→半露月→章印椭圆→地月双球），把进度隐喻做进图形。
7. **文学性中文 + 机器性纹理**：诗句（"折射进真理未校准的裂缝"）压在代码雨/点阵上，人文与数据主义并置。

## 效果与动画

**运动哲学**：运动像老式显示器刷新——短促、线性感、低幅度。不做弹跳、不做大幅位移，一切动效都服务于"场景推进"的仪式感。

**过渡默认**：
- 标准：`color .2s cubic-bezier(0.4, 0, 0.2, 1), background-color .2s cubic-bezier(0.4, 0, 0.2, 1), border-color .2s cubic-bezier(0.4, 0, 0.2, 1)`
- 入场：`opacity .3s cubic-bezier(0, 0, 0.2, 1), transform .3s cubic-bezier(0, 0, 0.2, 1)`，同级元素错峰 0.06s / 0.12s / 0.18s
- 悬停：色彩反相 0.2s；位移不超过 2px

**持续动画**：
- 滚动提示浮动：2s ease-in-out 上下 4px 循环
- 代码雨字符流（AGI 场景）：字符随机刷新，行滚动缓慢下坠
- 星野闪烁：随机像素点 opacity 0.3-1 慢闪

**关键帧动画**：
```css
@keyframes hoverRayReveal {
  0%   { stroke-dashoffset: 1px; }
  100% { stroke-dashoffset: 0; }
}
@keyframes hoverRayGlow {
  0%   { opacity: 0; }
  45%  { opacity: 0.95; }
  100% { opacity: 0.42; }
}
@keyframes hoverRayEndpoint {
  0%   { opacity: 0; transform: scale(0.35); }
  100% { opacity: 1; transform: scale(1); }
}
@keyframes hintFloat {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-4px); }
}
```
（hoverRay 系列用于流程地图：悬停时虚线路径 stroke-dashoffset 描线揭示 + 端点图标 scale 弹出 + 辉光呼吸。）

## 响应式策略

**断点哲学**：场景叙事在小屏改为纵向滚动的标准区块堆叠；像素网格感保持，元素尺寸按 4px 网格缩放。

- **Header**：≥768px 水平导航；<768px 汉堡钮 + 全屏竖排菜单
- **Hero**：≥1024px 四角散点；768px 以下改为左对齐堆叠（标题 → 副题 → 注释盒 → 标语），背景点阵图 cover 居中
- **Stats**：5 列 → 2 列（1024px）→ 1 列（768px），插画列整块插入第 2 列之后
- **终端按钮组**：横排 → 纵向堆叠（768px），按钮撑满宽度
- **流程地图**：环形路径 → 纵向虚线时间轴（768px），图标缩至 64px
- **Footer**：双列链接 → 纵向堆叠

**关键适配**：
- 巨型字号用 `clamp()`：64px → clamp(36px, 8vw, 64px)
- 边距 --hero-edge-x：40px → 16px（移动端）
- 点阵背景图移动端降低点阵密度（省性能），装饰性星野直接隐藏

## 可访问性与最佳实践

**色彩对比**：白字黑底 21:1；灰字 #7A7A7A 黑底约 5.3:1（正文级达标）；反白按钮黑字白底 21:1。

**聚焦状态**：1px 白色实线焦点框 + 2px offset 黑色间隙（终端光标感），禁止 `outline: none` 无替代。

**触控目标**：移动端按钮最小 44px 高，导航链接行高 ≥48px。

**运动**：`@media (prefers-reduced-motion: reduce)` 下停用浮动/闪烁/描线动画，入场元素直接置为最终态。

## 实现说明

- **组件结构**：单文件 HTML + 原生 CSS/JS，零构建；场景为纵向 section 堆叠，IntersectionObserver 触发入场
- **CSS 自定义属性**：全部色彩/间距/字号收敛到 `:root`，组件只引用变量
- **字体加载**：Fusion Pixel 12px Mono zh_hans 通过 CDN `@font-face`（woff2）加载，fallback `"SimSun", monospace`；像素字体建议 `image-rendering: pixelated` 心态对待图像
- **点阵影像**：三种实现任选——(a) canvas Bayer 抖动实时渲染渐变/形状；(b) 预处理 1-bit PNG（`image-rendering: pixelated` 放大）；(c) 1-bit 像素艺术生图。禁止直接放连续灰阶照片
- **动画**：原生 CSS + IntersectionObserver 即可，无需动画库；滚动场景推进可用 CSS `scroll-snap-type: y mandatory` 增强仪式感
