### Feature Cards（页面主体，4 张）

## 完整提示词 (Full Prompt)

# 设计风格：MiMo Warm Halftone（暖纸半调）

## 设计哲学

### 核心原则

这是「印刷品气质的软件落地页」：底子是暖白纸张，纹理是老式半调网点印刷，唯一饱和色是一道橙色荧光笔。它用纸张的温度中和 AI 产品的冷感，用印刷网点暗示「内容与创作」，用一枚手写感的胶带高亮标记出宣言词。所有结构面（卡片、窗口、面板）都像纸叠纸——靠 1px 暖发丝线与极柔阴影分层，绝不用强阴影或玻璃拟态。

### 视觉气质

**情感关键词**：
- *纸感温暖* — 米白纸底（#FCFAF8）与暖驼色带（#E8D7C1 系）营造的书页温度
- *印刷手作* — 半调网点、字符噪点、斜切胶带高亮，都是"印出来/贴上去"的手工痕迹
- *克制的宣言* — 全页只有一处橙色高亮、一处纯黑页脚，稀缺性让宣言词成为视觉锚点
- *工程可信* — 界面窗口模型精确还原真实产品 UI，让"能力"可被亲眼验证

**此设计不是什么**：
- 不是玻璃拟态/霓虹渐变的科技风（无 blur、无发光）
- 不是纯白极简冷淡风（底色永远偏暖，绝不使用 #FFF 之外的冷灰）
- 不是多彩 SaaS 风（全页只有橙色一个饱和色，其余全为暖中性）
- 不是重投影立体风（阴影只有一种：0 12px 32px 的 6% 透明度柔影）

### 此风格的 DNA

#### 1. 橙色胶带荧光笔高亮（Marker Tape）
标题关键词后压一块 `skewX(-8deg)` 的橙色平行四边形（#FF6500），带 2px 深墨描边与轻微旋转，像一条贴歪的荧光胶带。全页仅出现一次，是绝对的视觉锚点。出现在 Hero 主标题。

#### 2. 半调网点场（Halftone Field）
桃橘色圆点（radial-gradient 点阵，7-8px 间距）沿对角线方向疏密渐变、边缘溶解，铺在媒体面板底板与通栏色带上。它是"印刷网点"的直白引用，为大面积留白提供质感而不抢内容。

#### 3. ASCII 字符噪点纹理（Glyph Noise）
Hero 背景铺极淡的字符场（`·#*+@mIo1l0` 类，透明度 3-4%），远看是纸张噪点，近看是终端字符——为暖纸风格嵌入一枚工程基因。

#### 4. 编号发丝线列表（Numbered Hairline List）
Feature 文案列用 01/02/03 粗体序号 + 正文 + 暖发丝线（rgba(125,113,70,.35)）分隔，线宽不满栏。这是杂志目录页的排版语言，替代图标卡片列表。

#### 5. 暖纸三层底（Warm Paper Layering）
主底 #FCFAF8 → 暖纸面板 #F5EFE6 / 驼色带 #E8D7C1 → 纯白卡面 #FFFEFA，三层全是暖调，用色温而非明度分层。

#### 6. 墨色胶囊按钮（Ink Pill）
999px 全圆角、#151C13 深墨绿黑底、白字、右箭头随 hover 平移。下载按钮变体内部是「图标 + 双行小字（主名 + 副注）」的紧凑信息块。

#### 7. 纯黑二维码页脚（Ink Footer）
全页唯一的纯黑区块，与暖纸主体形成硬切反差，白色字标 + 白框二维码阵列，收尾利落。

## 设计 Token 系统（DNA）

### 色彩策略

**色彩聚焦**：95% 的画面是暖中性（米白纸底、驼色带、深墨绿黑），唯一饱和色是橙色 #FF6500，只用于荧光笔高亮与极少数强调点。半调网点用低透明度桃橘色，属于"纹理"而非"色块"。

### 字体系统

**字体配对**：
- **展示/UI 字体**：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif` — 全站单一字族，靠字重与字距做层级；中文紧排大标题是气质核心。

### 间距与布局

- **区块间距**：`clamp(28px, 8.77px + 4.95vw, 80px)`，Feature 卡之间 24-40px，Hero 下沿留 120px 呼吸
- **容器宽度**：正文容器 `min(1200px, 100% - 2*gutter)`；Feature 卡容器 `1240px`；页脚 `1600px`
- **网格间隙**：双栏卡片 gap 40-64px；按钮组 gap 12-16px
- **非对称模式**：Feature 卡左右两栏宽度比约 55:45（媒体宽、文案窄），左右交替

**常见间距值**：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 px；`--gutter: clamp(12px, 4vw, 40px)`

### 边框、表面与阴影

**圆角策略**：交互件与 CTA 全圆角（999px）；窗口模型 13px；卡片/面板 12px；小部件 8px/4px。圆角只用这几档，不混用中间值。

**边框**：1px 实线；分隔线用暖棕 `rgba(125,113,70,.35)`，卡描边用极淡 `rgba(21,28,19,.08)`。

**阴影系统**：

| Token | 值 | 用法 |
|:------|:------|:------|
| `shadow-float` | `0 12px 32px rgba(21,28,19,.06)` | 全站唯一阴影：悬浮窗口/媒体卡 |
| （无 hover 阴影变化） | — | hover 只动 transform/opacity |

**纹理与图案**：
- 半调网点：`radial-gradient(circle, rgba(214,142,102,.5) 1.3px, transparent 1.7px)`，`background-size: 7px 7px`，叠加对角线性渐变做疏密溶解
- 字符噪点：内联 SVG data-URI，字符场（`·#*+@mIo1l0`）以 3-4% 不透明度平铺，`background-size: 240px`
- 胶带高亮：`skewX(-8deg)` 橙色平行四边形 + 2px 深墨描边 + `rotate(-.5deg)`

## 效果与动画

**运动哲学**：克制的"纸片落位"。位移不超过 8px，只做透明度与轻微上移，让内容像卡片轻轻放到纸面上。

**过渡默认**：
- 标准：`transform .2s, opacity .25s`
- 入场：`opacity 0 → 1` + `translateY(8px → 0)`（IntersectionObserver 触发）
- 悬停：箭头平移 2-3px、按钮微提亮，无阴影/缩放变化

**持续动画**：
- `download-shiny-sweep`：下载按钮上光带周期性扫过（translateX -100% → 100%，约 3.6s 循环）
- `typewriter-caret-blink`：输入框光标 1s 闪烁（opacity 1/0 交替）

**关键帧动画**：
```css
@keyframes hero-pill-enter{ from{opacity:0;transform:translateY(8px)} to{opacity:1;transform:none} }
@keyframes hero-pill-word-in{ from{opacity:0;transform:translateY(40%)} to{opacity:1;transform:none} }
@keyframes download-shiny-sweep{ 0%{transform:translateX(-100%)} 65%,100%{transform:translateX(100%)} }
@keyframes typewriter-caret-blink{ 0%,49%{opacity:1} 50%,100%{opacity:0} }
```

## 响应式策略

**断点哲学**：全部字号/间距用 `clamp()` 流式缩放（设计宽度 1440px），布局断点只做两档重排（1024px / 768px）。

- **Hero**：字号流式缩放；下载按钮组在 768px 以下堆叠为单列全宽
- **Feature 卡**：1024px 以下双栏改上下堆叠（媒体在上），卡高随内容；768px 以下序号列表字号下调
- **Footer**：4 列导航 1024px 改 2 列，768px 改 1 列；二维码阵列换行
- **装饰元素**：半调带与字符噪点保留（它们不占布局空间），胶带高亮在小屏保持倾斜不变形

**关键适配**：
- 标题：`clamp(20px, 6.66px + 3.43vw, 56px)` 流式，小屏最小 20px
- 间距：`--gutter: clamp(12px, 4vw, 40px)`，区块间距 `clamp(28px, ..., 80px)`
- Hero 大图：`zoom: min(1.25, 100vw / 1440px)` 等比缩放，不裁切

## 可访问性与最佳实践

**色彩对比**：深墨 #151C13 对暖白纸 #FCFAF8 对比度 >15:1；正文 #66645F 对纸底 >5:1；页脚灰白 #BDBDBD 对纯黑 >9:1。橙色 #FF6500 仅作高亮块底色（其上文字仍为深墨），不作小字色。

**运动**：`prefers-reduced-motion: reduce` 时禁用全部动画与位移入场（`.reveal` 直接可见）。

## 实现说明

- **组件结构**：单文件 HTML + 原生 CSS/JS，零构建；`:root` 集中定义全部 Token，组件只引用变量
- **CSS 自定义属性**：色彩/圆角/阴影/字体/间距/动效全部变量化；深色模式用 `html[data-theme="dark"]` 覆盖底色与墨色 Token（页脚固定纯黑）
- **纹理实现**：半调网点 = `radial-gradient` 点阵 + 对角 `linear-gradient` 疏密遮罩；字符噪点 = 内联 SVG data-URI 平铺；胶带高亮 = `::before` + `skewX`
- **字体加载**：系统字族，无外部字体请求
- **动画**：原生 CSS keyframes + IntersectionObserver 入场，无动画库
