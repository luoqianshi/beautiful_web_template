### Header

### Hero
全屏黑底 + 覆盖 60% 画面的点阵像素云（薄荷绿到灰的抖动渐变，像被像素化的人脸/星云）。文字压在点云下缘：左下角超大 TRAE 字标 + 两行巨型中文标语「智能无限，协作无间」（约 88px，字重 600，行高 1.1）；右下角为转化区——两行产品一句话（TraeCode / TraeWork）+ 双下载按钮（薄荷绿实心 + 白描边）+ 绿点引导的积分提示行。左右分栏、上下咬合的非对称布局。

### Features（编号卡片轮播）
横向轮播（embla）三卡并排：每卡顶部先是一行薄荷绿等宽编号 `[01]` `[02]` `[03]`，其下白色标题（20-24px 字重 600），再下是深灰演示面板（#121314，4px 圆角）承载 UI 示意图——聊天对话框 / SOLO-IDE 双模式切换图（虚线连接 + 绿色描边块）/ 智能体节点网格（紫 Docs、蓝 MCP、绿 Web 彩色图标块 + 虚线总线）。卡片下方灰色正文（14px）分段落。演示面板是"设计图"而非截图：虚线、小色块、终端行。

### Footer

## 设计哲学

### 核心原则

这是"工程师写给工程师"的界面：黑底是终端的延伸，薄荷绿是唯一的生命信号。设计追求**精确**（2px 圆角、1px 发丝线、等宽编号）与**信号感**（大面积黑上只有极少量高饱和绿），拒绝一切装饰性柔和。点阵像素云是"数据被具象化"的隐喻——AI 的思考以像素密度呈现。排版本身就是产品气质：巨型字标宣告品牌自信，小号等宽标签提供终端秩序。

### 视觉气质

**情感关键词**：
- *克制的锋利* — 圆角 2-4px、发丝边框、零装饰阴影，一切边缘都像被 CLI 裁切过
- *信号绿* — #32F08C 是整站唯一色彩，出现即代表"可操作 / 生命力 / AI"
- *数字尘埃* — 点阵云的抖动渐变像低分辨率扫描的星云，冷静而有流动感
- *巨型宣言* — 页脚裁切巨字与 hero 大标带来不容置疑的品牌自信

**此设计不是什么**：
- 不是玻璃拟态 / 柔和渐变的"高级感"——没有毛玻璃、没有弥散光斑
- 不是多彩 SaaS——全站只有一个色相（薄荷绿），彩色只在示意图小图标中微出现
- 不是圆角友好型——拒绝 12px+ 大圆角与胶囊卡片

### 此风格的 DNA

#### 1. 点阵像素云（Halftone Dot-Matrix Cloud）
Hero 背景由数千个 3-5px 小方块组成的抖动云：绿色方块按密度衰减混入灰色方块，形成像素化的体积感。出现在首屏 60% 区域，是全站最重的视觉资产。

#### 2. 薄荷绿单点强调（#32F08C on Black）
绿色只出现在：CTA 按钮、编号、徽章、公告条、页脚巨带。黑底与绿的对比高达 12:1，绿即是"下一步"。

#### 3. 等宽编号索引 `[01]`
功能卡顶部的 JetBrains Mono 绿色编号，字距 0.35px，像代码行号一样组织信息层级。

#### 4. 巨型字标裁切收尾（Giant Cropped Wordmark）
页脚通栏薄荷绿底 + 超大黑色 TRAE 字标被视口底边裁切，形成印刷海报式句号。

#### 5. 菱形 ◆ 母题
Logo 字母 E 内嵌菱形、入场动画 `rotate(45deg)` 缩放、图标装饰均用 45° 方块，贯穿微观细节。

#### 6. 演示面板即设计图
功能卡内的产品示意全部用"设计图"语言表达：虚线连接器、色块节点、终端代码行，而非真实截图。

## "大胆要素"（签名元素）

1. **点阵像素云 Hero**：canvas/SVG 生成数千个 3-5px 抖动方块，绿灰双色密度衰减，像被低分辨率扫描的 AI 星云——纯 CSS 渐变无法替代
2. **页脚巨型裁切字标带**：#32F08C 通栏 + 380px 黑色 TRAE 字标被底边裁切，是页面最响亮的句号
3. **等宽绿色索引 `[01]`**：把功能区变成"代码清单"，信息层级即行号
4. **2px/4px 锐角体系**：全站无大圆角，终端窗格般的锋利边缘
5. **菱形 ◆ 母题**：logo 内嵌、入场 `rotate(45deg)` 缩放、绿色方点引导符，微观处反复出现
6. **薄荷绿渐变按钮**：唯一的彩色面，四段绿色渐变（#3EE1A3→#32F08C→#60F2BD→#A0FDE7）在黑底上像发光条
7. **示意图即设计图**：虚线连接器 + 色块节点 + 终端行，不用真实截图，保持"蓝图"质感

这些元素定义此实现并防止通用输出。

## 效果与动画

**运动哲学**：短促、精确、不拖泥带水——像 CLI 响应。所有过渡 0.15-0.3s，缓动 `cubic-bezier(0.4, 0, 0.2, 1)`。

**过渡默认**：
- 标准：`color 0.15s, background-color 0.15s, border-color 0.15s cubic-bezier(0.4,0,0.2,1)`
- 入场：`transform: scale(0) rotate(45deg)` → `scale(1) rotate(45deg)`，0.3s（菱形母题）
- 悬停：`transform: translateY(-1~-2px)` + 边框变绿，0.2s

**持续动画**：
- 公告条：可选的横向文案轮播（opacity 0.3s 交叉淡入）
- 点云：静态为主，可加极慢的透明度呼吸（8-12s，±4% 透明度）

**关键帧动画**：
```css
@keyframes dot-in{
  0%{transform:scale(0) rotate(45deg);opacity:0}
  100%{transform:scale(1) rotate(45deg);opacity:1}
}
@keyframes spin{to{transform:rotate(360deg)}} /* 回到顶部 ⊕ 图标 */
```

## 响应式策略

**断点哲学**：桌面优先的开发者受众，但移动端保持"宣言感"——大标缩小而非换风格。

- **Hero**：桌面左右分栏对角咬合 → 平板堆叠（标题在上、CTA 在下）→ 移动端点云透明度降至 40% 避免压字
- **功能卡**：三列 → 平板两列/横向滚动 → 移动端单列纵向
- **页脚巨带**：字标随视口宽度缩放（`clamp` / vw 单位），始终保持裁切效果

**关键适配**：
- 标题尺寸：88px → `clamp(40px, 8vw, 88px)`
- 间距缩减：100px 区块间距 → 64px（≤768px）
- 装饰点阵：移动端仅保留 hero 点云与角部装饰，隐藏次级点阵

## 可访问性与最佳实践

**色彩对比**：白/黑与 #32F08C 均超 12:1；灰字 #A6AAB5 在 #0A0B0D 上约 7:1，达标。

**聚焦状态**：2px 绿色外环（`outline: 2px solid #32F08C; outline-offset: 2px`），全站统一。

**触控目标**：按钮最小 44px 高，导航链接含 12px 内边距扩展热区。

**运动**：`prefers-reduced-motion: reduce` 时关闭点云呼吸与入场位移，仅保留透明度变化。

## 实现说明

- **组件结构**：单文件 HTML + 原生 CSS/JS，零构建依赖；点云用 `<canvas>` 绘制（或 SVG 方块阵列）
- **CSS 自定义属性**：`:root` 全量 Token，组件只引用变量；深浅翻转用 `html[data-theme="light"]` 覆盖底色/墨色（白底 + 黑字 + 绿点缀不变）
- **字体加载**：Google Fonts Inter（400/500/600/700）+ JetBrains Mono（400/500/600）
- **动画**：CSS transition + IntersectionObserver 触发入场；无需动画库
