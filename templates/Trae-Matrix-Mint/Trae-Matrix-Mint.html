[01 · PHILOSOPHY]

克制的锋利，唯一的信号绿

这是"工程师写给工程师"的界面：黑底是终端的延伸，薄荷绿是唯一的生命信号。设计追求精确与信号感，拒绝一切装饰性柔和。

[01]

克制的锋利：2/4px 锐角与发丝边框

radius 2px radius 4px
1px hairline border
box-shadow: none —— 层级靠表面明度差建立

一切边缘都像被 CLI 裁切过：按钮 2px、面板 4px，全站禁用 12px 以上大圆角与胶囊卡片。

[02]

信号绿 #32F08C：黑底上唯一色相

#32F08C
contrast on #0A0B0D ≈ 12:1 —— 绿即"下一步"

绿色只出现在 CTA、编号、徽章与页脚巨带；四段渐变 #3EE1A3 → #32F08C → #60F2BD → #A0FDE7 在黑底上像发光条。

[03]

数字尘埃：点阵抖动云是 AI 的像素隐喻

3-5px squares · dithered density falloff · green + gray

数千个抖动方块按密度衰减混色，形成像素化的体积感——数据被具象化，冷静而有流动感。

[04 · SIGNATURE]

七个签名要素，防止通用输出

这些元素定义此实现：缺任何一个，页面都会滑向"普通深色 SaaS"。

[01]

点阵像素云 Hero

canvas 生成数千个 3-5px 抖动方块，绿灰双色密度衰减，像被低分辨率扫描的 AI 星云。

[02]

页脚巨型裁切字标带

#32F08C 通栏 + 超大黑字标被底边裁切，是页面最响亮的句号。

[03]

等宽绿色索引 [01]

把章节组织成"代码清单"，信息层级即行号，字距 0.35px。

[04]

2px / 4px 锐角体系

全站无大圆角，终端窗格般的锋利边缘，零装饰阴影。

[05]

菱形 ◆ 母题

字标内嵌、入场 rotate(45deg) 缩放、绿色方点引导符，微观处反复出现。

[06]

薄荷绿渐变按钮

唯一的彩色面：四段绿色渐变在黑底上像发光条，悬停位移 1px。

[07]

示意图即设计图

虚线连接器 + 色块节点 + 终端行，不用真实截图，保持"蓝图"质感。

[05 · COMPONENTS]

组件样式与交互

按钮、输入框、徽章全部引用 :root Token；绿色外环是唯一的聚焦语言。

[06 · MOTION]

短促精确，像 CLI 响应

所有过渡 0.15-0.3s，缓动 cubic-bezier(0.4, 0, 0.2, 1)；入场沿用菱形母题的 scale + rotate(45deg)。

/* 标准过渡 */ transition: color 0.15s, background-color 0.15s, border-color 0.15s cubic-bezier(0.4,0,0.2,1); /* 悬停 */ transform: translateY(-1px); 0.2s
prefers-reduced-motion 时仅保留透明度变化
@keyframes dot-in { 0% { transform: scale(0) rotate(45deg); opacity: 0; } 100% { transform: scale(1) rotate(45deg); opacity: 1; } } /* 点云呼吸：8-12s，±4% 透明度，可关闭 */
点阵云静态为主，呼吸为可选增强
