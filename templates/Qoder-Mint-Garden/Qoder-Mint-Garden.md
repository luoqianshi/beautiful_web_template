## 布局创意 (Layout Ideas)

### 公告条 + 导航
顶部 36px 浅绿公告条（居中小字 + 关闭按钮），下接 64px 吸顶导航：左侧 Logo + 文字商标，中部文本链接（产品/企业版/价格/能力市场/资源/活动），右侧"登录"文本链接 + 白底描边"下载"胶囊按钮。导航滚动后悬浮于内容之上，带极淡投影。

### Hero
浅薄荷灰（#f2f4f2）大留白单列左对齐：小尺寸胶囊徽章（跑马灯式文案）→ 超大两行标题（"全新 Qoder / 你的智能体工作台"）→ 深绿主按钮 + 白底描边次按钮。右下角一段右对齐的灰色小字副文案（两行，与标题底端对齐），形成非对称呼吸感。

### 产品展示区（绿色跑道）
通栏鲜绿（#80c776）区块，背景叠加深绿（#255a41）大弧线"跑道/叶片"条纹装饰（同心圆角弧带、带虚线描边与小圆点节点）。区块中央悬浮一个白色产品窗口 Mockup（macOS 红黄绿窗控 + 侧边栏 + 主面板），窗口顶部出血超出绿区上沿，营造"跃出画面"的层次。

### Feature 拼贴（QoderWake）
白底两栏：左侧文案栏（大标题 + 灰色正文段 + 绿色文字链接"体验 xx →"），右侧不对称卡片拼贴——一张竖高彩色卡（蓝绿渐变背景 + 白色 UI 小卡浮层）、一张窄灰卡（工牌/徽章实物感 Mockup）、一张横宽卡（风景背景大图 + 白色清单卡浮层）。卡片圆角 12-20px，靠背景色差而非描边分隔。

### FAQ
白底两栏，右栏手风琴列表：条目间 1px 极淡分隔线，问题 20px 左右中黑字，右侧细"+"图标，展开无边框卡片化，保持纸感阅读密度。

### Footer
浅灰（#f7f8f7）通栏：左侧 Logo + 大号 Tagline（"不止编程，无限创造"）+ 社交图标行；右侧 5 列文本链接分组（组标题灰色小字，链接黑色 14px，行距宽松）；底部备案信息小字 + 右下"返回顶部"胶囊按钮。

## 完整提示词 (Full Prompt)

# 设计风格：Qoder-Mint-Garden（薄荷绿园）

## 设计哲学

### 核心原则

这是一套"清新、可信、有生机"的 AI 工具营销语言：用大面积薄荷灰白留白建立秩序与专业感，只在关键处投入高饱和的绿色（CTA、产品舞台、装饰跑道），让绿色成为信号而非底噪。产品截图被当作"主角"请上舞台（绿色跑道区），营销文案退居其次。设计拒绝花哨的渐变堆叠与暗黑赛博感，追求"办公桌上的一盆绿植"式的亲和科技。

### 视觉气质

**情感关键词**：
- *清新（fresh）* — 薄荷灰白底 + 草木绿的低刺激组合
- *可信（trustworthy）* — 克制的字重、规整的网格、极少的阴影噪点
- *生机（organic）* — 大弧线跑道/叶片条纹、圆点节点、圆润胶囊
- *聚焦（spotlit）* — 鲜绿舞台把白色产品窗口衬托成绝对主角

**此设计不是什么**：
- 不是暗黑霓虹的"黑客风" AI 页面
- 不是五彩渐变的 SaaS 通用模板
- 不是高密度信息堆砌的文档站

### 此风格的 DNA

#### 1. 薄荷灰白画布 + 单点深绿 CTA
全页底色 #f2f4f2，正文近黑 #0f0d0c；唯一的高权重色是森林绿 #255a41 的胶囊主按钮。绿色只出现在"可点击"和"舞台"两处，稀缺即高级。

#### 2. 绿野跑道舞台区
产品展示区通栏鲜绿 #80c776，叠加深绿同心弧带 + 虚线 + 小圆点（跑道/叶片意象），白色产品窗口悬浮其上并顶部出血，制造 2.5D 层次。

#### 3. 非对称 Hero
标题左对齐超大字，副文案右对齐小灰字沉在右下角——左右不对角呼应，拒绝居中八股。

#### 4. 卡片拼贴（Mosaic）叙事
Feature 区不用等宽卡片网格，而用"竖高彩卡 + 窄灰卡 + 横宽图卡"的不对称拼贴，每卡内再叠一层白色 UI 浮卡，形成"卡片中的卡片"。

#### 5. 胶囊几何
按钮、徽章、标签一律 999px 胶囊；卡片 12-20px 圆角；全站找不到一个直角容器。

#### 6. 极淡阴影 + 内高光
几乎不用投影分层，改用 1px 边框与背景色差；确需悬浮感时用 48px 大扩散极淡阴影 + 顶部 0.5px 白色内高光（"薄瓷"质感）。

## 设计 Token 系统（DNA）

### 色彩策略

**色彩聚焦**：三段式——薄荷灰白（画布 90%）× 森林绿（交互与舞台 8%）× 中性灰（辅助文字 2%）。绿色系内部再分三级：浅绿 #cdecc8（公告条/软背景）、鲜绿 #80c776（舞台/图形）、深绿 #255a41（CTA/重色）。

| Token | 值 | 用法与上下文 |
|:------|:------|:----------------|
| `background` | `#f2f4f2` | 页面主底色（薄荷灰白） |
| `background-alt` | `#f7f8f7` | Footer / 次级区块底色 |
| `surface` | `#ffffff` | 卡片、产品窗口、浮层 |
| `mint` | `#cdecc8` | 顶部公告条、软强调背景 |
| `grass` | `#80c776` | 跑道舞台通栏、图形装饰 |
| `forest` | `#255a41` | 主按钮、深色弧带、重色图形 |
| `link-green` | `#42643e` | 文字链接（"体验 xx →"） |
| `foreground` | `#0f0d0c` | 标题与主文字 |
| `foreground-2` | `#141414` | 次级标题 |
| `muted` | `#636261` | 正文灰字 |
| `muted-2` | `#838280` | 辅助说明、页脚组标题 |

### 字体系统

**字体配对**：
- **展示字体**：`"Instrument Sans", system-ui, sans-serif` — 中性偏几何，标题字重仅 500-600，靠字号而非粗细建立层级
- **UI/正文字体**：同上，14px 起步的紧凑 UI 字号
- **等宽字体**：产品 Mockup 内部代码区用系统 mono

**字号阶梯与用法**：

| 元素 | 尺寸 | 字体 | 字重 | 字距 | 备注 |
|:--------|:-----|:-----|:-------|:---------|:------|
| Hero 标题 | 56px / 1.15 | Instrument Sans | 500 | -0.5px | 两行断行，左对齐 |
| 区块标题 | 32px / 42px | Instrument Sans | 500 | -0.32px | 两行结构（产品名 + 一句话） |
| 卡片标题 | 26px / 32px | Instrument Sans | 500 | normal | 拼贴卡内部 |
| 引导标题 | 20px / 32px | Instrument Sans | 500 | -0.32px | FAQ 问题、小节标题 |
| 正文 | 14-16px / 1.6 | Instrument Sans | 400 | normal | 灰色 #636261 |
| 标签/徽章 | 12-13px / 22px | Instrument Sans | 500-600 | normal | 胶囊内小字 |
| 页脚链接 | 14px / 2.4 | Instrument Sans | 400 | normal | 行距极宽松 |

### 间距与布局

- **区块间距**：区块间留白 120-160px（提取到 `160px 0 0` 的区块内边距），呼吸感优先
- **容器宽度**：内容容器 1312px（视口 1440 - 两侧 64px 边距），页面最大宽 1440px
- **网格间隙**：拼贴卡间隙 24-36px；导航项间隙 36px
- **非对称模式**：Hero 文案左对齐 + 副文案右下角对齐；Feature 区左文案 40% / 右拼贴 60%

**常见间距值**：4 / 8 / 12 / 16 / 20 / 24 / 36 / 48 / 64 / 120 / 160 px

### 边框、表面与阴影

**圆角策略**：按钮与徽章 999px 胶囊；小控件 4-6px；卡片 12px（`--radius-border-radius-lg: 12px`）；大卡/窗口 20px；头像 50%。

**边框**：统一 `1px solid`，颜色只用 #e6e6e6 / #efefef / #bbc3b8 三档，几乎不用深色描边。

**阴影系统**：

| Token | 值 | 用法 |
|:------|:------|:------|
| `shadow-sm` | `0 1px 2px rgba(12,12,13,.1), 0 1px 2px rgba(12,12,13,.05)` | 胶囊按钮、小卡 |
| `shadow-md` | `0 0 12px rgba(0,0,0,.05), 0 0 48px rgba(0,0,0,.04)` | 悬浮产品窗口、浮层卡 |
| `shadow-inset-hi` | `inset 0 2px 4px rgba(0,0,0,.04), 0 .5px 0 rgba(255,255,255,.66)` | 胶囊按钮"薄瓷"内高光 |
| `shadow-side` | `-2px 0 12px -8px rgba(0,0,0,.1)` | 侧滑面板 |

**纹理与图案**：跑道区的同心弧带 + 虚线描边 + 小圆点节点；活跃对话热力图用绿色系点阵（4px 圆角方块，0.18-1 透明度分层）。

## 组件样式与交互

### 按钮

**主按钮**：
- 背景：`#255a41` 森林绿
- 文字：`#ffffff`，14px/500
- 圆角：999px 胶囊，内边距 12px 24px
- 阴影：`shadow-inset-hi` 薄瓷内高光
- 悬停：背景提亮（#2f6b4e 级），`transform 0.12s ease-out` 微上浮
- 激活：scale(0.98)

**次/描边按钮**：
- 背景：`#ffffff`；边框 `1px solid #dddddd`；文字 `#0f0d0c`
- 悬停：底色转 `#eeeeeb`，边框加深一档

**文字链接按钮**：
- 颜色 `#42643e`，尾随 "→" 箭头，悬停箭头右移 4px（`transform .2s`）

### 卡片
- 白底 + 1px `#e6e6e6` 描边 + 12-20px 圆角；无阴影或 `shadow-md`
- 拼贴卡用整块背景色（#b3dfe9 / #dad9d8 / 风景大图）代替描边，内层再浮一张白色 UI 卡
- 悬停：`transform 0.3s cubic-bezier(0.4,0,0.2,1)` 上浮 2-4px

### 输入框 / 命令面板
- 白底、1px 描边、8px 圆角；聚焦时描边转绿 + 2px 浅绿外光
- 产品 Mockup 内的对话输入用胶囊 + 占位灰字

### 导航
- 64px 高、白/毛玻璃底、吸顶；Logo（圆环叶形图标）+ 文字商标 20px/500
- 链接 14px `#141414`，悬停变灰或出现下拉（下拉为白卡 + `shadow-md`，4px 上移淡入）
- 右侧动作：文本"登录" + 白底胶囊"下载"

### 徽章/标签
- 胶囊形、12px 字、浅绿底 `#cdecc8` 或白底描边
- 状态徽章（Beta）用浅蓝 `#e9f6fe` 底 + 蓝字的小胶囊

### FAQ 手风琴
- 无卡片化：仅 1px 分隔线，20px 问题字，右侧 "+" 旋转 45° 变 "×"
- 展开动画 `opacity .2s` + 高度过渡

## "大胆要素"（签名元素）

1. **绿野跑道舞台**：鲜绿通栏 + 深绿同心弧带/虚线/圆点，把产品窗口顶出区块上沿——用"舞台思维"替代"截图平铺"。
2. **单点深绿 CTA**：全页只有一种重色按钮，绿色稀缺性 = 交互优先级。
3. **非对称 Hero 呼吸**：超大左标题 vs 右下沉副文案，留白本身就是构图。
4. **卡片中的卡片**：拼贴卡内再叠白色 UI 浮卡（评论卡、清单卡），微型叙事嵌套。
5. **薄瓷内高光**：按钮 `inset 0 2px 4px` + `0 .5px 0 rgba(255,255,255,.66)`，塑料感全无、瓷感十足。
6. **徽章跑马灯**：Hero 顶部小胶囊内多条文案横向流动轮播，静中有动。
7. **点阵热力图**：绿色方点矩阵（活跃对话图）作为"数据感"装饰，与跑道圆点呼应。

这些元素定义此实现并防止通用输出。

## 效果与动画

**运动哲学**：动效克制、微位移、缓出为主；产品 Mockup 内部允许持续性"呼吸/流动"动画（虚线流动、光标闪烁、点阵脉冲），营销层本身安静。

**过渡默认**：
- 标准：`color .2s` / `background-color .18s, border-color .18s, color .18s`
- 入场：`opacity 1.2s cubic-bezier(0.22,1,0.36,1)` + 4-8px 上移
- 悬停：`transform 0.3s cubic-bezier(0.4,0,0.2,1)`；按钮 `transform 0.12s ease-out`

**持续动画**：
- hero-dash-flow：跑道虚线 `background-position` 循环流动（0%→10px）
- focus-breathe / thinking-pulse：0.55-1 透明度 + scale(0.9→1.08) 呼吸
- cursor-blink：46%-100% 消失的光标闪烁
- borderFlow：FeatureGrid 边框虚线四边循环流动

**关键帧动画**：
```css
@keyframes dropdownFadeIn {
  from { opacity: 0; transform: translateY(-4px); }
  to   { opacity: 1; transform: translateY(0); }
}
@keyframes codeGenerate {
  from { opacity: 0; transform: translateY(1.5px); clip-path: inset(0 100% 0 0); }
  to   { opacity: 1; transform: translateY(0); clip-path: inset(0); }
}
```

## 响应式策略

**断点哲学**：桌面优先的营销栅格；1024px 以下收窄留白，768px 以下拼贴改单列堆叠。

- **导航**：768px 以下收进汉堡菜单，下载按钮保留
- **Hero**：标题随断点 56px → 40px → 32px；副文案右对齐改左对齐跟随
- **产品展示区**：窗口 Mockup 等比缩放（transform scale 或 width 100%），弧带装饰保持
- **Feature 拼贴**：1024px 两卡并排、768px 单列；文案栏始终置顶
- **Footer**：5 列 → 2 列 → 手风琴式分组

**关键适配**：
- 标题尺寸用 clamp(32px, 4vw, 56px) 缩放
- 区块间距 160px → 96px → 64px
- 跑道弧带装饰在移动端只保留一条，避免噪点

## 可访问性与最佳实践

**色彩对比**：正文 #0f0d0c on #f2f4f2 ≈ 16:1；灰字 #636261 on 白 ≈ 5.8:1；白字 on #255a41 ≈ 8:1，全部达标。

**聚焦状态**：2px 绿色外描边 + 2px 浅绿外光，键盘可见。

**触控目标**：按钮最小高度 40px，胶囊内边距保证 44px 热区。

**运动**：所有持续动画与入场动画须实现 `prefers-reduced-motion: reduce` 降级（关闭流动/呼吸，保留透明度切换）。

## 实现说明

- **组件结构**：单文件 HTML + 原生 CSS/JS 即可实现；`:root` 落地全部 Token，组件只引用变量
- **CSS 自定义属性**：色彩/圆角/阴影/动效时长全 Token 化；深色模式可翻转 `--background`/`--foreground` 系列
- **字体加载**：Instrument Sans（Google Fonts CDN，400/500/600 三字重），回退 system-ui
- **动画库**：无须库；持续动画用 CSS keyframes，入场用 IntersectionObserver + `.reveal` 类
