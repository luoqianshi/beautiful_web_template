Qoder-Mint-Garden（薄荷绿园）
来源：真实站点逆向提取 · 模式：Light · 字体：Instrument Sans
设计哲学 · 核心原则

用大面积薄荷灰白留白建立秩序，只在关键处投入高饱和绿色——让绿色成为信号而非底噪；产品截图被当作主角请上舞台。

01 · Philosophy

设计哲学：清新、可信、有生机

文档开篇即定义这套语言追求什么、拒绝什么——情感关键词与"此设计不是什么"共同划定边界。

❋

清新 fresh

薄荷灰白底 + 草木绿的低刺激组合，长时间阅读不疲劳。

✓

可信 trustworthy

克制的字重、规整的网格、极少的阴影噪点。

↯

生机 organic

大弧线跑道、圆点节点、圆润胶囊，拒绝直角容器。

◎

聚焦 spotlit

鲜绿舞台把白色窗口衬托成绝对主角。

此设计不是什么

  • 不是暗黑霓虹的"黑客风" AI 页面
  • 不是五彩渐变的 SaaS 通用模板
  • 不是高密度信息堆砌的文档站

07 · Signature

大胆要素：七个防通用签名

  1. 绿野跑道舞台：鲜绿通栏 + 深绿同心弧带 / 虚线 / 圆点，把窗口顶出区块上沿。
  2. 单点深绿 CTA：全页只有一种重色按钮，绿色稀缺性 = 交互优先级。
  3. 非对称 Hero 呼吸：超大左标题 vs 右下沉副文案，留白本身就是构图。
  4. 卡片中的卡片：拼贴卡内再叠白色 UI 浮卡，微型叙事嵌套。
  5. 薄瓷内高光：inset 0 2px 4px + 0 .5px 0 白色高光，瓷感十足。
  6. 徽章跑马灯：Hero 小胶囊内多条文案横向流动，静中有动。
  7. 点阵热力图：绿色方点矩阵作为数据感装饰，与跑道圆点呼应。

08-10 · Motion / Responsive / A11y

动效克制、适配明确、对比达标

效果与动画

  • 标准 color .2s / bg .18s
  • 入场 opacity 1.2s + 4-8px
  • 悬停 transform .3s std
  • 按钮 transform .12s ease-out
  • reduced-motion 全降级

响应式策略

1024px768pxclamp(32,4vw,56)
  • 区块间距 160→96→64
  • 拼贴 2 列→单列堆叠
  • 导航收进汉堡菜单
  • 弧带装饰移动端仅留一条

可访问性

16:1 正文 on 画布
5.8:1 灰字 on 白
8:1 白字 on 森林绿
  • 聚焦 2px 绿描边 + 外光
  • 触控目标 ≥ 44px
How to use

把这份 md 当作 Prompt 使用

文档的结构即为生成顺序：先哲学、再 Token、再组件与签名要素，最后动效与适配约束。

STEP 1

整份投喂

将 Qoder-Mint-Garden.md 作为系统提示词或首条上下文交给生成 Agent。

STEP 2

Token 先行

要求先在 :root 落地色彩 / 圆角 / 阴影 / 动效变量，组件只引用变量。

STEP 3

签名校验

对照七个大胆要素逐条检查产出，缺任何一个都会滑向通用模板。
