# 设计风格：Bright Collab Blue-Green（明亮协作蓝绿）

## 设计哲学

### 核心原则

一套「明亮、克制、协作感」的 AI 协作平台设计系统：白色基底承载内容，品牌蓝 #3b72ff 负责一切可交互识别，协作绿 #43cf7c 表达「人 + Agent 共同在线」的生命感，橙色 #ff5733 只做少量强调。所有页面共享同一套 Token 真值（Web 与 Mobile 语义名映射到同一组值），组件圆润但不过分——卡片 16px、控件 8px、标签全胶囊。边框极轻（中性灰 12% 透明度），阴影极浅（卡片仅 1px 微阴影），层级靠表面色阶（#fff / #f5f5f5 / #e5e5e5）而非重投影。动效短而自然（140/200/260ms ease），永远提供 prefers-reduced-motion 降级。

### 视觉气质

**情感关键词**：
- *明亮可信* — 纯白底 + 中性灰文字，像一张干净的协作白板
- *友好协作* — 蓝绿双品牌色、在线绿点、吉祥物色块角色，传达「人与 Agent 一起工作」
- *轻盈圆润* — 胶囊标签、16px 圆角卡片、1px 轻边框，无压迫感
- *克制的活泼* — 点阵图、极光背景、粒子只作局部装饰，不抢内容

**此设计不是什么**：
- 不是深色科技风/霓虹赛博风（全站强制浅色）
- 不是重拟物/玻璃拟态主导（玻璃层仅用于顶栏与个别浮层）
- 不是大字报营销落地页（除 Hero 外字号克制，UI 密度偏高）
- 不是多彩糖果风（彩色只出现在品牌蓝/绿/橙与状态色，其余为中性灰阶）

### 此风格的 DNA

#### 1. 蓝绿双品牌梯度
`linear-gradient(90deg, #3b72ff, #43cf7c)` 出现在 logo 波纹、加载轨道与品牌装饰；蓝=平台/交互，绿=协作/在线，二者并置即品牌识别。

#### 2. 点阵活跃度可视化
7 列圆点矩阵（8px 点、9px 行距），点透明度随数值变化：紫 rgba(88,28,230, .09+.62v) 为主、绿 rgba(67,207,124, .2+.55v) 为强调点。用于「本周协作节奏/热度」，是全站最具辨识度的数据装饰。

#### 3. 点阵网格画布底
`radial-gradient(circle, 边框色 1px, transparent 1.1px)` 26px 平铺 + 径向 mask 渐隐，用于无限画布与 Flow 页，营造「无限白板」空间感。

#### 4. 极光网格 pastel 背景
个人主页与首页卡片层叠三层大尺寸 radial-gradient（蓝/薰衣草/薄荷，透明度 .4-.78），白底上形成柔和极光，是浅色主题下的「氛围层」。

#### 5. 胶囊化一切标签
状态徽章、快捷想法、计数、Tab、Agent 在线胶囊全部 999px 圆角；小字号（10-12.5px）+ 600 字重 + 浅色底（品牌蓝 12%、绿 12%、橙 12%）。

#### 6. 吉祥物色块角色
Flow 页底部漂浮黄/紫/蓝/橙圆形角色（白色竖条眼睛），大小错落、轻微浮动动画，为工具型产品注入 playful 人格。

#### 7. 品牌转场加载（clWave）
页面启动时蓝→绿波浪点阵加载动画：点按序 scale .8→1.2、颜色从品牌蓝过渡到协作绿，配合横向扫光轨道，形成「品牌化等待体验」。

## 效果与动画

**运动哲学**：短、自然、克制——一切过渡 140/200/260ms ease；入场位移 8-10px 级别；不做长滚动叙事动画。

**过渡默认**：
- 标准：`transition: background .14s ease, border-color .14s ease, color .14s ease`（Token：fast 140ms / normal 200ms / slow 260ms）
- 入场：`pop` / `viewIn`：opacity 0→1 + translateY(8-10px) scale(.99-.994)→none
- 悬停：卡片 translateY(-2px) + 边框/阴影 150-180ms；按钮按下 translateY(1px)

**持续动画**：
- `clWave`：品牌点脉冲，蓝→绿变色（启动转场）
- `clTrack`：扫光 translateX(-120%→330%)
- `pulse`：在线绿点 box-shadow 3px→5px 呼吸
- `ui-skeleton-shine` / `ui-sheen`：骨架扫光 translateX(-100%→100%)
- `mfRise` / `mfMatIn`：Flow 画布素材生长入场
- `clBob`：吉祥物上下浮动

**关键帧示例**：
```css
@keyframes pop { 0% { opacity: 0; transform: translateY(8px) scale(.99); } 100% { opacity: 1; transform: none; } }
@keyframes clWave {
  0%, 100% { opacity: .25; transform: scale(.8); background-color: rgb(59 114 255 / .24); }
  45% { opacity: 1; transform: scale(1.2); background-color: rgb(59 114 255 / .95); }
  62% { opacity: .9; background-color: rgba(67, 207, 124, .9); }
}
@keyframes pulse { 0%, 100% { box-shadow: 0 0 0 3px rgba(18,163,122,.12); } 50% { box-shadow: 0 0 0 5px rgba(18,163,122,.05); } }
```

**降级**：全局 `@media (prefers-reduced-motion: reduce)` 将所有 animation/transition 压至 .001ms。

## 可访问性与最佳实践

**色彩对比**：主文字 #171717 / 白底 ≈ 16:1；次级 #404040 ≈ 10:1；muted #737373 ≈ 4.6:1（达标）；品牌蓝 #3b72ff 白字 ≈ 4.0:1（大字号/600 字重达标，小字用 #285ce6）；绿字用深档 #17a05a / #127a4c 保证小字对比。

**聚焦状态**：统一 `0 0 0 3px rgb(59 114 255 / .18)` 聚焦环；输入聚焦边框转品牌蓝。

**触控目标**：控件高 28/32/36px 三档，Web 主交互用 36px；图标尺寸规范 12/14/16/18/20/24px，禁止非规范尺寸。

**运动**：全站 prefers-reduced-motion 降级；启动转场在数据就绪后一次性退出，避免内容闪烁（is-booting 机制）。

**语义**：Tab 用 role=tablist/tab，弹层 role=dialog + aria-modal，状态点配文字标签，图标按钮带 aria-label。

## 实现说明

- **组件结构**：单文件 HTML + 原生 CSS/JS 即可还原；Token 层独立成 `tokens.css`（:root 变量），页面级 CSS 只引用变量；保留语义别名层（--ink/--brand/--surface 等）便于迁移
- **CSS 自定义属性**：色彩/圆角/阴影/间距/动效/控件尺寸/图标尺寸/z 轴全部 Token 化；z 轴唯一来源：base 0 / sticky 40 / overlay 50 / popover 60 / modal 70 / toast 90
- **字体加载**：零外部字体，系统栈直出；展示标题可用品牌艺术字图（PNG）替代文字
- **动画库**：无需第三方库；IntersectionObserver 触发入场 + CSS keyframes；canvas 粒子用原生 2D context
- **图片资源**：品牌 logo/艺术字/吉祥物/设备样机为 PNG 资产；头像用色块 + 首字 fallback；图标用内联 SVG sprite（icons.js 注入 data-icon）
- **多页一致性**：所有页面共享 tokens/ui/styles/brand/system 五层 CSS，页面级 CSS（home/flow/settings-page/space/login）只写布局与签名区块；新页面按此分层即可自动继承风格
