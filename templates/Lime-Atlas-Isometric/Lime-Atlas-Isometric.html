需要更换模型或者 AI Agent 吗？

通过受支持的 MCP 宿主接入，可继续使用已有 Agent 和模型通道。模型名称本身不决定兼容性，宿主需要支持标准 stdio MCP 并遵循工具合同。

我的源码、业务数据和凭据会被上传吗？

本地优先，不上传源码。数据库只读取显式授权的 Schema 元数据，不读取业务行；凭据通过环境变量名引用，不写入认知资产。

什么规模的项目适合使用？

可先由 Agent 生成项目雏形，也可更早接入。支持规模取决于索引的信息密度、token 大小以及宿主模型上下文。首次索引需逐个阅读受管文件，支持按批次继续。

支持哪些数据库？

示例支持 MySQL 与 PostgreSQL 的 Schema 元数据读取。数据库卷为可选项，需显式接受证据并完成绑定与生命周期治理。

绿色结果是否意味着 AI 理解一定正确？

治理检查证明已编码的结构与治理条件成立，语义仍需用源码、Schema、测试、运行结果和人工审查核对。完整交付与模型充分理解是不同维度。

交付与治理：证明当前身份，保留恢复边界

全景索引可按 Chunk 与 Cursor 完整交付，并通过 Receipt、Challenge 与 Attestation 校验身份和覆盖。正式更新经过校验、审阅、CAS 和原子写入；失败时保留事务证据，按可证明的状态继续或恢复。
