# 设计风格：DeepSeek Harness Navy Glow（深空蓝辉光）

## 设计哲学

### 核心原则
以"产品即主角"为信条：用深空蓝的静谧包裹真实的产品界面实景，让工具本身成为最大的视觉说服力。拒绝花哨的插画与营销修辞，一切装饰（极光、星尘、网格）都服务于"深邃、可信、开源科技"的气质。设计语言的根基是**深空蓝渐变 × 发丝级暗面 × 液态玻璃**。

### 视觉气质

**情感关键词**：
- *深邃（Deep）* — 深空蓝到近黑的垂直渐变，像夜空包裹产品
- *克制（Restrained）* — 字重只有 400/500，没有粗野的黑体咆哮
- *精密（Precise）* — 0.5px 发丝边、等宽微标签、负字距标题
- *可及（Approachable）* — 白色胶囊按钮与圆角窗口让科技感不冰冷

**此设计不是什么**：
- 不是霓虹赛博朋克（没有高饱和撞色与故障效果）
- 不是纯黑极简（Hero 有蓝色温度，不是死黑）
- 不是拟物卡片堆砌（卡片是暗面 + 发丝边，不是厚重阴影）

### 此风格的 DNA

#### 1. 深空蓝渐变 Hero + 极光辉光
Hero 背景从钢蓝（#2e5080 附近）向近黑（#0a0a0a）垂直过渡，叠加 2-3 团大半径模糊极光（rgba(122,170,255,0.4) 级），形成"星云包裹"感。

#### 2. 产品实景窗口作为 Hero 视觉
不使用插画，而是 1:1 的应用窗口 mockup：macOS 红黄绿灯（#ff6058 / #ffbd2e / #28c840）、侧边栏、聊天气泡、输入栏，配超大投影 `0 24px 72px rgba(0,0,0,0.2)` + 1px 白色内描边。

#### 3. 近黑 Bento 卡片 + 浮动 UI 切片
#0a0a0a 舞台上放置 #151517 卡片（圆角 24px），发丝边 `0 0 0 0.5px rgba(255,255,255,0.08)` 内发光；卡内是悬浮的 UI 切片（文件卡、Diff 面板、任务卡）。

#### 4. 星尘粒子 CTA
终局区块用蓝色径向辉光 + 白色微粒散点 + 淡透视网格，把"加入生态"渲染成星空邀约。

#### 5. 液态玻璃悬浮胶囊导航
滚动后导航收拢为居中悬浮胶囊：`backdrop-filter: blur(32px) saturate(1.25)`，发丝白边，圆角 100px。

#### 6. Fragment Mono 微标签
"HARNESS"、"预览版" 等徽章用等宽字体 + 大字距（0.22em），是全页唯一的"技术签名"装饰。

## "大胆要素"（签名元素）

1. **产品实景 Hero**：应用窗口 mockup 以 1:1 界面细节（红黄绿灯、侧栏、聊天气泡、输入栏）替代插画，超大投影使其从深空蓝背景中浮起
2. **深空蓝→近黑垂直渐变**：Hero 不是平涂深色，而是有温度的星云渐变，向下无缝融入 #0a0a0a
3. **浮动 UI 切片叙事**：Bento 卡内不放截图而放"活的" UI 零件（文件卡叠 Diff 面板、定时任务卡），用层级讲述产品能力
4. **星尘粒子 CTA**：蓝色径向辉光 + 粒子散点 + 透视网格，把转化区渲染成星空
5. **液态玻璃胶囊导航**：滚动时全宽导航 morph 成居中玻璃胶囊（blur 32px + saturate 1.25）
6. **Mono 大字距微标签**：Fragment Mono + 2.64px 字距的"预览版/HARNESS"徽章，全页唯一技术感装饰
7. **发丝边替代阴影**：暗面卡片几乎不用投影，靠 0.5px 白色内发光发丝边定义轮廓

这些元素定义此实现并防止通用输出。

## 效果与动画

**运动哲学**：安静地浮现——一切动效都是"从深空中浮起并消散模糊"，绝不弹跳、不旋转。

**过渡默认**：
- 标准：`color .2s, background-color .2s, box-shadow .2s`
- 导航 morph：`background-color .3s, border-color .3s, backdrop-filter .3s`
- 入场：`opacity 0 + translateY(20px) + blur(6px)` → 清晰，400-600ms，可分级 stagger

**关键帧动画**：
```css
@keyframes hero-enter {
  from { opacity: 0; transform: translateY(20px); filter: blur(6px); }
  to   { opacity: 1; transform: translateY(0);    filter: blur(0); }
}
```
- 滚动入场（Bento 卡）：IntersectionObserver 触发同类上浮
- `prefers-reduced-motion: reduce` 时全部位移/模糊动画降级为纯淡入

**循环产品演示（落地页还原的渐变交互）**：原站的产品预览区是循环播放的 UI 故事，全部以渐变淡入淡出（`loop-in` 关键帧 + 负延迟错相）实现：
- 首屏窗口对话循环（14s）：用户气泡 → 已思考 → 回答逐行浮现 → 收束重置
- 插件卡（10s）：插件列表整体滚动 + 新插件行渐变进入 + 开关滑块往复开合
- 交付卡（9s）：文件卡依次浮现并整体上移，Diff 行逐行揭示
- 工作流卡（12s）：输入气泡 → 执行中 → 结果卡与触发说明的故事循环
- Trace 卡（10s）：跨度条逐条揭示，「执行轨迹 / 耗时」标签与数据面板交叉淡入
- `prefers-reduced-motion: reduce` 下所有循环动画关闭，元素以静态终态呈现

## 响应式策略

**断点哲学**：桌面 2 列 Bento 优先，1024px 以下降为单列；Hero 窗口 mockup 等比缩放。

- **Hero**：1024px 下标题降至 32px，窗口 mockup 缩放并可裁切侧栏
- **Bento 网格**：1024px 降为单列，卡片内 UI 切片保持水平排布
- **导航**：768px 下隐藏语言切换与次要按钮，仅保留 logo + 下载
- **CTA**：按钮组 768px 下换行居中

**关键适配**：
- 标题尺寸：40 → 32 → 28px 阶梯
- 区块间距：160 → 120 → 80px
- 辉光装饰保留但半径缩小；粒子密度降低

## 可访问性与最佳实践

**色彩对比**：白色/近白正文在 #0a0a0a 与深蓝渐变上均 > 7:1；muted 文字（0.45 白）仅用于辅助信息

**触控目标**：按钮最小高度 40px，胶囊按钮内边距 11px 24px 起

**运动**：所有入场动画在 `prefers-reduced-motion: reduce` 下移除位移与模糊，仅保留透明度过渡

## 实现说明

- **页面定位**：`DeepSeek-Harness-Navy-Glow.html` 为产品介绍落地页（Hero → 能力 Bento → 开发者体验 → 生态 CTA → 页脚），不含组件库演示区块，也不含任何公司主体文字（版权、公众号等）
- **组件结构**：单文件 HTML + 原生 CSS/JS，零构建；`:root` 集中 Token
- **CSS 自定义属性**：色彩/圆角/阴影/间距全量 Token 化（参考 `--ds-*` 命名）
- **字体加载**：Google Fonts 加载 Montserrat 400/500、DM Sans 400/500、Fragment Mono 400，中文回退 Noto Sans SC / PingFang SC
- **动画**：纯 CSS keyframes + IntersectionObserver，无第三方库
- **图片资源**：产品 UI 全部用 HTML/CSS mockup 还原（本风格的"图"就是界面本身）；星尘/辉光用 CSS 渐变与 box-shadow 粒子实现
