我是 DeepSeek Harness，DeepSeek 开源的 harness 架构，基于 Cordis 的「一切皆插件」架构构建。我既可以是桌面应用，也可以通过代码启动为网页。
我可以帮你：
  1. 辅助日常工作 —— 整理资料、分析表格、撰写文档、制作汇报。
  2. 写代码、改仓库 —— 理解项目、修复问题、开发功能、运行测试。
  3. 查资料、核对信息 —— 搜索资料、交叉查证，给出有来源的结论。
  4. 处理文件与任务 —— 运行脚本、批量处理文件、后台跑任务，随时查看进度。
  5. 安装插件、拓展能力 —— 使用现有插件，或写你自己的插件，定制专属的工作方式。

开发者体验

同一种能力，两种接入方式——命令行起步，或拿源码自己构建。

命令启动

安装 Node.js 后，通过 npx 启动 Web UI。

# 一行命令启动
$ npx deepseek-harness@latest start
→ http://localhost:3737

源码安装

获取完整项目源码，并按照仓库说明完成安装。

$ git clone https://github.com/deepseek-ai/harness.git
$ cd harness && npm install
$ npm run dev
