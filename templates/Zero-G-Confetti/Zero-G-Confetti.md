## 布局创意 (Layout Ideas)

### Header（52px 导航 + 公告条）

固定顶栏高 52px，白底 95% 不透明 + 8px 背景模糊；左侧彩色折线 Logo + 产品字标，中部 14.5px 导航链接带下拉caret，右侧「描边胶囊 + 近黑胶囊」双 CTA 与语言选择器。导航下方紧贴一条公告条：黑色小胶囊徽章（✦ + 12.5px 白字）+ 14.5px 公告文案 + 「Read post →」式链接 + 右端关闭 ×，底边 1px hairline。整条 header 总高约 92px。

### Hero（满屏失重场）

整屏 900px 高的居中单列：顶部小尺寸 Logo 锁up（图标 + 20px 字标），其下 80px/88px、字重 450 的近黑大标题（桌面大屏可放大到 107px/107px、字距 -2.14px），再下 36px 间距处并排双胶囊 CTA（浅灰描边胶囊 + 近黑实心胶囊）。**整个 Hero 背景是一层稀疏彩屑粒子场**：60–90 枚 2–6px 的蓝/红/粉/橙/紫短划与圆点，随机旋转、极低密度地散布在纯白上，制造"失重漂浮"氛围。留白慷慨到近乎空旷，标题是唯一重力中心。

### Orb Media（深色晕环媒体卡）

非对称双栏：左栏 17.5px 灰正文（#45474d）+ 描边胶囊按钮，右栏一张近黑（#05070c→#1b1c20）圆角 24px 媒体卡，卡内用径向渐变绘出一圈蓝色晕环（#3279f9 / #8ab4f8 辉光），环心叠加白色发光产品名文字。媒体卡是白页面上唯一的"深色重力井"，与彩屑的轻形成对比。

### Statement（编辑式非对称宣言）

hairline 分隔线后进入宣言区：左栏 42px/43.68px、字重 450、字距 -0.73px 的两行大标题顶格放置；右栏正文下沉到区块下半部、宽度约 5 列，形成对角线阅读动线。区块垂直内边距 120px/88px。

### Feature Explorer（交替特性列）

多组「文 + 媒体」交替双栏（12 列网格、gutter 64px）：文本侧为 28–32px 小标题 + 17.5px 正文 + 胶囊链接；媒体侧为 24px 圆角深色晕环卡或浅灰容器卡（#f8f9fc）。组间以 120px 垂直节奏排布，总高可达数千 px 的长滚动叙事。

### Use Cases / Chips（用例滑轨）

一行可横滑的胶囊 chip（rgba(183,191,217,.09) 底、14.5px 字），选中态翻转为近黑底白字；下方对应用例卡片横向 slider。

### Blog Cards（三列文章卡）

三列等宽卡片：顶部程序化封面（彩屑/晕环母题的 CSS 渐变图），下部 12.5px 分类标签 + 20px/26px 标题 + 14.5px 摘要；卡面无重阴影，仅 hairline 边框与 16px 圆角，悬停整体上浮 3px。

### Newsletter（灰底订阅卡）

1296px 宽、380px 高的浅灰容器卡（#f8f9fc，圆角 24px，内边距 60px 48px）：左侧 32px 标题 + 正文，右侧胶囊输入框 + 近黑订阅按钮；卡内可再撒少量彩屑呼应 Hero。

### Final CTA / Download（下载区）

居中堆叠：42px 标题 + 平台胶囊按钮组（近黑主胶囊带下载图标），入场时卡片从 scale(.88) 弹性放大到 1。

### Footer（超大字标收尾）

上栏左 28px 标语式标题 + 右两列 14.5px 链接组（列标题 12.5px 灰）；中部一枚**占满容器宽度的超大字标**（clamp(120px, 21vw, 320px)、字重 500、字距 -0.04em，字母可带 ±2° 微旋转）作为视觉签名；底栏 hairline 分隔后放 Logo、12.5px 法律链接与社交图标。页脚总高约 800px。

## 完整提示词 (Full Prompt)

# 设计风格：Zero-G-Confetti

## 设计哲学

### 核心原则

把页面当作一间失重舱：背景无限白、信息极度克制，唯一的"质量"留给近黑标题与胶囊按钮；彩色只以毫米级碎屑存在，像舱内漂浮的纸屑，暗示动势而不抢夺阅读。深色媒体卡是舱窗——透过它看到发光的引擎晕环。整体追求"轻到几乎消失，但每个落点都精确"的工程感极简。

### 视觉气质

**情感关键词**：
- *失重（Weightless）* — 900px 满屏 Hero 只放一行标题与两枚按钮，其余交给漂浮彩屑与白。
- *精确（Engineered）* — 灰阶 12 级 Token、12 列网格、72px 页边距，所有落点可测量。
- *俏皮一克（One gram of play）* — 彩屑、字标微旋转、弹性入场，是克制体系里唯一允许的玩笑。

**此设计不是什么**：
- 不是渐变满铺的 Aurora/Mesh 风格：全页无大面积渐变，渐变只存在于深色媒体卡内部。
- 不是玻璃拟态：白底不透明、无彩色玻璃面板，仅顶栏 8px 背景模糊。
- 不是重阴影卡片流：阴影只给浮层与媒体卡，普通卡面靠 hairline 与留白分层。

### 此风格的 DNA

#### 1. 彩屑粒子场（Confetti Field）
Hero 与订阅卡背景稀疏散布 2–6px 彩色短划/圆点（蓝 #3279f9、红 #ea4335 系、粉、橙、紫），随机旋转与慢速漂移。密度低到"几乎注意不到"，却是风格的第一识别物。

#### 2. 近黑胶囊按钮对（Ink Pill Pair）
主按钮 #121317 底 + 白字、次按钮 rgba(183,191,217,.1) 底或 1px 描边透明底，全部 9999px 圆角、36–44px 高。成对出现（浅左黑右）是源站 CTA 的固定语法。

#### 3. 深色晕环媒体卡（Orb Glow Card）
24px 圆角近黑卡内一圈蓝色径向晕环 + 中心发光白字，是白页面上唯一的深色块，承担"产品演示窗"角色。

#### 4. 超大页脚字标（Giant Wordmark）
页脚中部一行占满容器宽度的产品字标，字号随视口缩放（21vw 级），字重 500、紧字距，字母可微旋转，把品牌名变成建筑构件。

#### 5. Hairline + 120px 呼吸节奏
区块之间仅 1px rgba(33,34,38,.06) 分隔线；区块内边距 120px/88px/72px 三档，长滚动也不拥挤。

#### 6. 450 字重的可变标题
标题不用 bold：可变字体 450 字重 + 负字距（-0.73px ~ -2.14px），黑而不吼，是 Google 系排印的签名手感。

## "大胆要素"（签名元素）

1. **彩屑失重场（会回应你）**：JS seeded 随机生成 70 枚 2–6px 粒子（短划与圆点），色取 confetti 五色；rAF 引擎驱动慢漂 + 慢自转，指针靠近 110px 内被斥力推开、移开后弹性归位，Hero 场随滚动视差滞后——彩屑不是贴图而是"舱内活物"。
2. **超大页脚字标**：`font-size: clamp(120px, 21vw, 320px)`、line-height .95、letter-spacing -.04em；逐字母 `rotate(±1.5°)` 微倾斜，制造"手工摆字"的俏皮。
3. **晕环媒体窗**：双层 radial-gradient 蓝环 + 中心发光标题；环带轻微呼吸（scale 1→1.03，6s）。
4. **Ink Pill 双 CTA 语法**：所有 CTA 成对"浅左黑右"，胶囊几何全程统一。
5. **450 字重负字距大标题**：拒绝 bold，用可变中黑 + -2.14px 字距获得"黑而安静"的排印。
6. **弹性入场**：下载卡 scale(.88)→1、chip translateY(6px)→0，缓动 `cubic-bezier(.34,1.85,.64,1)` 的回弹只给入场，不给悬停。
7. **Hairline 长滚动**：10000px 级长页仅靠 1px 线与 120px 留白分章，无彩色区块带。
8. **打字机标题 + 闪烁光标**：Hero 标题 42ms/字 逐字显现，光标按源站 blink 曲线闪烁后淡出；减少运动时直接全文。
9. **difference 光标环**：26px 圆环以 mix-blend-mode:difference 反色跟随指针（lerp .2），悬停可交互元素放大到 46px——白底黑环、暗底白环，一套几何两副面孔。
10. **字标逐字母落位**：页脚超大字标进入视口后逐字母 60ms stagger 上浮回弹，落位保留 ±2° 微旋转，像手工摆字被轻轻放下。

## 效果与动画

**运动哲学**：轻物体慢漂、重物体快落——彩屑以 10s 级慢漂移存在并回应指针与滚动，UI 反馈一律 0.12–0.2s 干脆完成；入场允许一次回弹，悬停只位移不弹跳。

**过渡默认**：
- 标准：`background-color .15s, color .15s, border-color .15s, box-shadow .15s`
- 入场：`opacity .18s cubic-bezier(.165,.84,.44,1), transform .18s cubic-bezier(.165,.84,.44,1)`
- 悬停：`transform .18s cubic-bezier(.165,.84,.44,1)`，按钮/卡片上浮 -2~-3px

**持续动画与交互引擎**：
- 彩屑引擎（rAF）：每枚粒子正弦慢漂（8–14s 周期）+ 慢自转；指针 110px 半径内受斥力推开（lerp .08 回弹）；Hero 粒子场随滚动以 0.12 系数视差滞后
- `orb-breathe`：6s ease-in-out 无限，晕环 scale(1→1.03)，并叠加滚动联动旋转 `--orb-rot`；悬停 brightness(1.3)
- 打字机标题：42ms/字 逐字显现 + 闪烁光标（`caret-blink` 1.1s），完成后光标淡出；`aria-label` 保留全文
- 自定义光标环：26px difference 混合圆环 lerp .2 跟随指针，悬停可交互元素放大到 46px；粗指针/减少运动时隐藏
- 下拉子导航：hover/focus 展开，opacity+translateY(6px) 0.16s ease-out-quart，Escape/外点关闭
- 用例滑轨：scroll-snap 横滑 + chips 双向同步 + 前后箭头；公告关闭走 0.18s 淡出
- 页脚字标：进入视口后逐字母 60ms  stagger 上浮回弹落位（保留 ±2° 微旋转）

**关键帧动画**：
```css
@keyframes chip-in { from { opacity: 0; transform: translateY(6px); } }
@keyframes card-settle { from { transform: scale(.88); } to { transform: scale(1); } }
@keyframes caret-blink { 0% { opacity: 0; } 10% { opacity: 1; } 100% { opacity: 0; } }
@keyframes agy-fade-out { from { opacity: 1; } to { opacity: 0; } }
```

## 响应式策略

**断点哲学**：1024px 收网格、767px 收导航；留白与字号随视口连续缩放（clamp），不做跳变式重排。

- **Hero**：107px（≥1600）→ 80px（桌面）→ clamp(40px, 9vw, 64px)（移动）；彩屑数量减半。
- **特性/宣言双栏**：≤1024px 堆叠为单列，媒体卡移到文本下；对角布局取消。
- **导航**：≤767px 中部链接收进汉堡面板，双 CTA 仅保留主胶囊。
- **页脚字标**：随 vw 连续缩放，永不换行溢出（`font-size: clamp(72px, 21vw, 320px)` + overflow hidden）。

**关键适配**：
- 页边距 72 → 24 → 16px；区块内边距 120 → 72 → 56px。
- 彩屑场在 ≤767px 降低密度并禁用漂移（省电）。
- 媒体卡圆角 24 → 16px。

## 可访问性与最佳实践

**色彩对比**：`#121317`/白 ≈ 16.9:1；正文 `#45474d`/白 ≈ 9.2:1；旁注 `#5f6368`/白 ≈ 5.9:1；暗色 `#e8eaed`/`#1b1c20` ≈ 13.5:1，均过 AA/AAA。彩屑为纯装饰，不承载信息。

**聚焦状态**：2px `#8ab4f8` 实环 + 2px offset（暗色同色）；键盘可达全部 chip 与滑轨。

**触控目标**：按钮/chip ≥36px 高，移动端 CTA 44px；关闭 × 热区 32px。

**运动**：`prefers-reduced-motion: reduce` 时彩屑静止、晕环停呼吸、入场改纯 opacity、所有 transition ≤.01s。

## 实现说明

- **组件结构**：单文件 HTML、零构建；`:root` 落全部 Token，`html[data-theme="dark"]` 翻转表面/文字/描边组（彩屑与晕环保持不变）。
- **CSS 自定义属性**：灰阶 12 级 + 语义别名两层；组件只引用语义别名。
- **字体加载**：Google Fonts 的 Google Sans Flex（wght 400..700）与 Google Sans Code；离线回退 system-ui / ui-monospace。
- **动画库**：无需外部库；彩屑用 seeded RNG 生成 span，IntersectionObserver 触发 `.reveal` 入场（translateY 6px 级）。
- **合规**：示例文案与名称均为测试数据（产品名 Demo Lift、模型名 Demo 5 Preview 等）；页脚资质行统一 `测试备案号 00000000000000`。
